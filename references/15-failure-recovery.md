> **V59 SOURCE FIREWALL — CURRENT RULE:** Product websites, local projects, original HTML/CSS and reference clips are **INFORMATION ONLY**. Any screenshot, real UI capture, existing site image, logo, font, webpage-derived frame, layout or reference footage mentioned below is **NOT permitted in the output video** by default, even after cropping, recoloring or redrawing. Build ALL visible scenes from new original tool-generated art instead; factual source inspection remains allowed. A separately provided asset needs explicit inclusion authorization. This V59 rule overrides all conflicting examples below. See `references/117-source-firewall-v59.md` and root `SKILL.md`.

# Decision table for poor results
| Failure | Action | Fallback / when to stop |
|---|---|---|
| No local product | Ask for one source from intake choices | use adequate direct description; no fabricated features |
| URL unavailable | try authorized browser/fetch once; explain | user HTML/source/screenshot/description |
| Script generic | replace abstract benefit with specific situation; re-score hook | fewer words, show real behavior |
| Hook clickbait | remove unsupported premise; use demonstration | quiet action hook |
| Too many features | keep one; ledger others | one proof + CTA |
| No song | request actual file or waiver | script/brief only |
| No TTS | find local/authorized provider or ask supplied VO | labeled scratch voice only if delegated; no final quality claim |
| No alignment | phrase-level measured segments or manual marks | no fake word timings |
| Bad 3D | bevel/light/material test; if still poor replace | 2D vector hero, actual product shot |
| No renderer | probe alternative and 1-second test | starter fallback only if adequate; otherwise partial artifacts |
| UI errors | log console and requests, reproduce isolated, wait asset load | accurate authorized screenshot not broken live iframe |
| Too static | change focus, mask/camera, layer motion, same motif | add meaningful 1–2 events not unrelated VFX |
| Too chaotic | reduce secondary motion, hold proof, simplify transitions | stable main element |
| Bad pacing | listen/align, adjust shot boundaries and lead/tail | shorten agent script if needed, never rewrite locked script |
| Text clips | measure final layout, split lines, enlarge safe margins | shorten display text only |
| Black/freeze warning | examine actual interval, check intentional hold | fix decoder/asset or document intentional hold |
| Render crashes | isolate shortest reproduction, inspect error | lower preview res/cache; avoid unsupported effects |
| Missing audio on export | check maps, duration, decode; remux | re-mix, verify audio stream |

After two failed attempts at a nonessential effect choose simpler high-quality route. For a blocker that cannot be solved, deliver real partial artifacts and explain exactly what is missing. Don't enter endless retry loops, disable QA, claim playback you didn't inspect, or promise to finish later.

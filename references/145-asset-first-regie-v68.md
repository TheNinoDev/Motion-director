# V68 — Asset-first visual direction (NOT another geometry template)

## Why this correction exists

In multiple real RobloxLARP trials, other agents ignored the editing program and built text-on-dark-background, straight-edged polygons, small code cards and repeated shape morphs. Adding more shapes, effects and rules did not make the footage interesting. The user wants recognisable pictorial subjects, actual icons, emoji-like illustrated artwork, typography with personality, textures, material changes, 2.5D and expressive object acting. **A scene with no supplied or newly authored pictorial content is often missing its hero.** This is a producer choice, not an automatic requirement that every scene contain ten icons.

## Do this BEFORE drawing your first generic rectangle

1. **Inventory useful assets:** user-supplied MP4/audio/graphics; authorized standalone icons in the product project; independently licensed SVG/PNG icon libraries; emoji/illustration collections; original pictorial illustrations; textures and 3D props. Distinguish *reference for facts* from *approved for output*. Use `scripts/asset_scout_v68.py` on the exact permitted directories and review its generated sheet. If zero useful assets are available, author a small original asset pack first. Do NOT interpret “no assets supplied” as “shapes and text are the entire film.”
2. **Visual concept options:** for every important story beat consider (A) character/object acting, (B) visual metaphor using an icon/emoji/illustration, (C) physical material/3D transformation, (D) kinetic typography with a deliberate shape or object. Choose the route that says the most with the fewest elements. A typographic-only masterpiece is valid; a default deck of captions is not.
3. **Make the focal object substantial.** A pictorial subject at 25–60% of frame height can work better than a 40-pixel icon beneath a 110-pixel headline. It needs silhouette, recognizable affordance, depth, color and lighting or texture appropriate to the idea. Rotate, bend, reveal, swap layers and animate parts rather than sliding a whole flat card. A standalone PNG/SVG is a *source for a moving object*, not permission to keep it static.
4. **Asset-to-action map:** write one sentence per shot: `OBJECT (asset ID) starts as X; on WORD/BEAT it does Y; after it changes viewers know Z; its edge/gesture/color moves into next scene as ...`. If the sentence only says “logo appears while title fades”, rethink the shot.
5. **Preflight proof:** render the storyboard with *actual approved assets and legible typography*. No placeholders for the hero in the full film. Inspect 3 intentionally different crops in phone scale. Only then build the timeline. Import `image` layers in `starter/composite_film/compositor.py` and group them; use its real transforms, masks, parented objects and time-sampled shutter when appropriate. A custom renderer is not a shortcut around composing a film.

## What artwork can be used?

- **Original:** create hand-authored SVG, drawn illustration, 3D mesh, procedural detail, or an authorized generated image; save editable source and stable PNG when needed. `examples/asset-first-v68/illustrations` includes FIVE *real original editable multicolor pictograms*; a proof scene imports them through the actual compositor. They are examples for testing imports, not prescribed characters or a fixed style for all projects.
- **Third-party icon/emoji sets:** independently licensed Lucide SVG (ISC), Tabler icons (MIT) or Microsoft Fluent Emoji assets (check the particular asset, project license and edition). Download from OFFICIAL sources; pin file/version, retain attribution/notice, sanitize and pre-render. Fluent Emoji is pictorial/colorful; Lucide is simple linework. A line-icon set alone cannot replace rich illustration. OpenMoji is CC BY-SA 4.0 and needs careful compatibility/attribution checks; do not casually sublicense it. Fonts also require license checks; do not ship unlicensed fonts.
- **The user's own RobloxLARP icon assets:** the user *now expressly requests icons from the site for this campaign*. Treat this as a limited, case-specific authorization to use individually identified RobloxLARP-owned icons if rights can be established, NOT permission to embed page screenshots, existing UI, website illustrations in bulk, scraped HTML/CSS, logos, reference-film visuals, or generic assets from unrelated websites. Log each icon's exact file/source, owner/authorization, role and transformations. Other projects still need separate authorization. If in doubt use an independent licensed asset or original artwork instead of quietly scraping.
- **Reference films (Claude, NOIZ etc.):** analyze rhythm, silhouette variety, color, object staging, reveal principles. Never reuse their icons, scene imagery, music, frames or original style wholesale. The demo objects included with this skill are not copies of those films.

## Picture-first example for a RobloxLARP script protection ad

Weak: large word `OBFUSCATION`, rectangular code card, two horizontal bars, word `VM`, card changes color. High-frequency motion doesn't fix its visual poverty.

Better: an illustrated script booklet with visible personality is grabbed by a duplicate; the duplicate spreads into little document copies; a **different material** (gold key) tracks into frame and passes to a protective emblem. The shield doesn't simply appear behind a headline: its rim catches the travelling key, the body flexes under the impact, and its halo becomes the next scene's threshold. Show the functions as a conceptual future feature where appropriate, not as proof of already deployed protection. Avoid implying absolute anti-theft guarantees.

The example can be executed as `python starter/composite_film/compositor.py examples/asset-first-v68/scene.json work/v68-scene --at 1.0 --at 2.0 --size 360` after verifying dependencies. **Do not copy these sample shots verbatim into a final film.** The lesson is asset diversity, intentional semantic acting and concrete editor use.

## Reject the familiar anti-pattern

If the main film has only `rect/path/text` layers, only sharp-corner silhouettes and 90% of shots are floating panels, challenge it BEFORE final render. Inspect assets; replace at least the most visually important panel with pictorial storytelling, not ten decorative emoji stickers. If a storyboard has six headings but no legible visible actions, stop and rewrite the visual concept. Deliver a documented exception only when the topic genuinely calls for typography-only design.

## 2. Build a visual grammar before constructing layers
For a structured planning record, copy `examples/creative-v38.json` and replace every fictional field with the current commission; run `python scripts/creative_gate.py work/creative.json`. The gate checks concept-family coverage, claim/proof references, exact beat continuity, shared anchors, repeat patterns, and required fields. It cannot verify factual truth or aesthetics; do not mark unverified proof as verified. For every beat write: actual audio interval, main claim, **visible action**, main object, supporting motion, outgoing anchor, incoming anchor, proof asset, hold time. Write concrete verbs (folds, splits, stacks, turns, collides, aligns, reveals); reject generic "animates nicely". Keep one dominant subject per frame. Do not reuse the same central text/object layout across successive beats. Variation comes from scale, composition and semantic actions, not noise. Use authentic product detail and let it breathe. Choose two typography specimens with the actual copy; verify local font availability and license (no font binaries supplied). Select one palette and a coherent material vocabulary. Reserve metal, glass and jelly for meaningful actions; do not require them. Distinguish optical effects from physics.

### New recipe selection
| Intent | Recipe | Guardrail |
|---|---|---|
| Object follows curved arrival | arc_arrival | flat drawable; explicit 4 control points |
| Stack opens into fan | card_fan | 2–16 flat layers; draw order determines front card |
| Fan leaves progressively | cascade_exit | resolves prior endpoint; order recipes chronologically |
| Two subjects exchange focus at same anchor | matched_exchange | same parent and target later in draw order; crossfade, not geometry morph |
| Optical sweep through content | lens_pass | lens with explicit shape, background already drawn |
| Jelly arrival and recovery | compression_release | authored impulse, not contact solver |
| Sculpted metallic hero type | metal_reveal | short actual 3D text or metal volume; review sidewalls |

Eight extra primitive actions: lens_strength, dispersion, defocus, shadow_strength (shadow:true), glow_strength, transmission, extrusion, bevel_depth. Inspect allowed fields, not all layers support all actions. Use `--profile high` for native hero, `lossless` for master. No need for GUI or new renderer code.

## 4. Evidence and correction loop
Run commands in `work/study01/session.json` using argument arrays. `native_review` really renders the selected frames, then writes checksums for plan, explicit images/fonts, PNGs and backend report. Run `verify_review` after edits: stale sources or changed PNGs must fail. These fingerprints are not proof of aesthetics; default system fonts and nested mesh resources are not fully fingerprinted. If uncertain render the exact excerpt instead of blindly changing parameters. Compare at same time and resolution. Use `review_ledger.py` (guide 73) for specific observations; never claim playback/listening without actual access.

## 5. Repair decision examples
- **Too choppy**: check actual outgoing and incoming motion vector + persistent anchor before altering timing. If gap is accidental, extend layer lifetime and overlap until new motif readable. Do not hide with glow.
- **Cheap chrome**: verify bevel, antialias and native still. Adjust light contrast and roughness; do not increase bloom indiscriminately.
- **Generic fan/stack**: if it cannot represent a real problem, remove it. Use proof cropping or an interaction instead. Choose different layouts for different products.
- **Too many effects**: demote support elements (opacity/scale/color), allow a clean hold. Text and evidence must remain legible.
- **Stale proof**: regenerate evidence after source changes; do not copy old review status. Protect unrelated scenes and audio from modifications.
- **Timing wrong**: measure real audio using existing tools, check accent and semantic sentence breaks; not every onset needs a cut. Final narration must remain intelligible.
- **Wrong API**: inspect catalog and existing examples, use explicit allowed values. If a capability is not implemented, use supported alternative or disclose blocker.

# V32 — soft motion, sculpted letters and typography selection

## Evidence from nine supplied reference clips
81 freshly extracted stills across nine clips were compared during development. Do not ask future users for any originals. This is a composition study, not a claim to have recovered the exact fonts, effects, timings or renderer. No reference frames are included in this skill.

- Clip 1: large solid metallic numerals, dimensional words, simple adjacent copy. Strong highlights occupy a controlled portion of the face; dark regions define the bevel. Use one sculptural number for a meaningful verified quantity rather than multiple metallic labels.
- Clip 2: repeated shapes develop into a dense dimensional structure. Repetition expresses scale or abundance; object silhouettes stay easy to identify. Build repetition from the same motif, not arbitrary particles.
- Clip 3: an enormous stacked question contrasts with tiny supporting text, then the real product becomes the focus. Maintain 2–3 type sizes and protect the hierarchy when the interface enters.
- Clip 4: individual characters become heavy dimensional artifacts and alternate with unadorned characters. Choose a short meaningful symbol; hold it still long enough to read before rotating.
- Clip 5: mostly plain typography, real data and charts, not CGI for every line. Keep smaller labels consistent and only animate an actual change.
- Clip 6: an expressive purple icon carries the emotional turn. Material/color are concentrated in one character. A small elastic reaction could communicate surprise; do not add decorative bounce by default.
- Clip 7: cropped macro views of metal/ring shapes alternate with large readable letters and tiny input elements. Crop the subject deliberately and maintain orientation/motion through the cut.
- Clip 8: UI actions, text, and sparse backgrounds retain their visual relationship. Let the result of an action become the next anchor.
- Clip 9: expressive color and product results are separated from black/white statements. Do not color every element just because the brand has an accent.

## Creative decision contract
1. Determine what is being communicated by each beat. Choose a dominant silhouette, a small supporting label only if useful, and the relationship to the next beat. Prefer strong large/small juxtaposition, not equal-weight headlines and captions.
2. Choose maximum two font families, usually one sans + optional mono/serif. A display font is not automatically better; pick according to brand, text and readable proportions. Test the actual message at 25% display size. Avoid excessive microtype or wordmarks rendered in arbitrary 3D styles.
3. Render three candidate frames with different font/weight/layout and at least two studio-light positions if using 3D type. Proof counters (O/A/8/R), spacing, edge highlights, actual depth and contrast. Select a candidate, not a rotating preset collection. Use 2D text for subtitles, longer words, dense feature labels. Chrome is a material, not mandatory branding.
4. Softbody must communicate physical cause/response (landing, pressure, release, elastic overshoot). Time the impulse at contact in picture time. Keep resting state truly at rest. Use lower strength for glass, moderate for rubber, higher only for intentionally playful scenes. Hard crystal should not bounce unless the story is deliberately stylized.
5. Test deformation at peak and recovery, test both ends of adjacent camera moves, review alpha edges and text legibility. Use whole-composite shutter sampling for fast solid/text motion. Compare at actual production fps; do not fix choppy motion by just adding excessive blur. If a silhouette folds into itself, reduce amplitude and review.
6. Complete the entire advert, listen to mix, compare three weak beats, revise before export. Never use FORM as a universal blueprint. Never claim an objective NOIZ percentage or that a weak-model benchmark has passed without running it.

The new damped modal deformation tool is deterministic and uses an analytic oscillator. It is not collision physics, FEM, cloth, a mass-spring lattice or real-world material simulation. For physically colliding objects, commission an appropriate dedicated simulator rather than pretend this renderer supports them.

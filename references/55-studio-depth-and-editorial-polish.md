# Studio depth and editorial polish (v19)
Reference-independent production instructions. The runtime agent never needs historical sample clips.

## Starting point: actual quality, not more effects
The previous sequential showcase uses similar panels, large headers, progress rails, repeated rectangular highlights and static compositions. For a short vertical film these turn a narrative into a presentation. Remove decorative rails unless genuinely useful, vary hierarchy and camera distance, and choose only effects motivated by the narration. A technical test cannot establish aesthetic parity.

## Decision recipe
1. Write a concrete narrative question with a provable product answer. Do not turn a single hook into a list of every feature.
2. Choose one visual metaphor that is independently recognizable: entangled rings for fragmentation, a single closed loop for cohesion, a transforming silhouette for simplification. Do not insert a random 3D ornament on unrelated copy.
3. Begin with an extreme crop or action, then reveal its context; retain a common silhouette, hue or movement direction across the cut. Use at most two hero CGI shots by default. `studio` supplies actual 3D geometry and camera/light tracks; use other existing engines for arbitrary typography, graphs, UI actions, particles, real footage.
4. After a complex macro, use a contrasting typography beat on one field of color. One phrase per frame is preferable to layered identical headings. Vary contrast/scale, not random filters. Use `type` for word-aligned captions if exact timings are available.
5. Deliver the proof: capture real product screenshot or actual interaction; use `studio:proof` for a continuous detail-to-context camera transform, or `ui`/`layers` if actual state changes matter. Never fake a UI response.
6. Finish with a calm, readable lockup. End text should be legible for 1.5–2s or actual VO CTA duration. No ornamental progress bar or full-screen CTA pill by default.

## Quality gate, concrete operations
- Sample first, middle, last and around cuts. Flag any overlapping proof/heading, accidental crop, jitter, repeated framing, irrelevant overlay, or blurry text. Inspect a 1x mobile-scale copy, not just canvas screenshot. Verify real audio timing and final audio independently.
- If CGI looks flat: choose narrower light strips / lower roughness and dark background; rotate light rather than keeping all object axes spinning. If edges shimmer: quality=1.0, or render at larger native project resolution; keep output honest. If floor horizon distracts disable floor; actual ground reflection is optional.
- If too static: add camera reframe or change representation within the same narrative beat, not a new random background. If too busy: remove an effect, reduce speed or hold the payoff. If a shot can be replaced by an unrelated promo without affecting the story, redesign it.
- Choose primary focal point and up to two supporting elements per beat; test several compositions before committing. Avoid generic template sequences. If all shots look identical, replace one with a high contrast type beat or a full bleed product crop; if none share an anchor, reuse motif or movement direction.
- Only report observed changes and actual successful render. If the model cannot visually inspect output, report lack of aesthetic review. Numerical frame tests are necessary, not sufficient.

## Cross-reference principles
- Different videos use different opening families: confession, question, scale mystery, data conflict, comedy, visual metaphor, UI friction, brand story. Don't repeat a single “viral hook” formula.
- Not all start loud. 3459 and 3462 use relatively restrained anticipation; 3456 starts with large geometry; 3463 begins with a task. Attention comes from contrast, unresolved meaning and readable action, not quantity of movement.
- Typographic rhythm uses accumulated words, cropped hero type, stable baselines, big-small contrasts. White-on-black common, but amber/purple/coral appear intentionally. Adapt palette to user brand.
- Scene density varies inside each film. Use held frames with lighting, subtle drift or changing focal point; speed up for proof montages then allow recovery. Avoid every scene ending in the same black fade.
- Transitions can preserve position, meaning, shape, scale or direction; not every transition must be visibly animated. A meaningful hard cut can be better.
- Most films have a specific topic and recognizable closing brand lockup. Treat series unity as shared voice/motifs, not copy-paste scenes. Do not copy their scripts, claims, logos, typography assets or footage.

# Quality gates — must inspect actual output
Stage A script: first line understandable, payoff answers promise, claims verified, no corny generic copy, one main story, meaningful CTA. Read script aloud or voice sample. If poor, rewrite before audio.
Stage B audio: actual voice file decodes, words match script, timing source documented, music supplied or waived, speech audible, mix not clipping, listen if possible. If only local scratch voice and no approval, do not label premium final. If cannot listen, state limitation and use objective checks. Do not invent word timing or beat sync.
Stage C storyboard: 3 distinct coherent style frames, clear safe areas, each shot has one focus and bridge. Check exact frame intervals and references. Inspect whether enough reading time. Use `check_shots.py` and `validate_plan.py` for structural tests; warnings require review.
Stage D preview: render 2–4 s hard shot first; then full low-res preview. Inspect first frame, 0.5/1/2/3s, mid of every shot, +/- 3 frames around each boundary, final hold. Make contact sheet or use player. At phone size confirm text, motion continuity, real product accuracy, no unwanted watermark, no invisible state. Do not rely on one thumbnail. Inspect timing on actual audio. Fix most severe three issues and rerender once; if still failing diagnose and simplify nonessential FX. Compare before/after; do not randomly regenerate everything.
Stage E export: verify file, ffprobe expected streams/dimensions/fps/duration, decode all with ffmpeg -v error -xerror, check black/freeze/loudness using existing check_render.py; quiet frames can be intentional. Inspect final export after encode, not just source. Be honest about unavailable subjective checks, tool failures, any preview-only audio, render substitutions. No claim “professional” just because validation passes.

Score 0–2 each: hook, clarity/payoff, human script, truth, visual hierarchy, motion meaning, continuity, variety, audio intelligibility, rhythm, brand/asset fidelity, mobile legibility, technical quality. Target ≥21/26, no zeros in truth, readability, audio (unless silent), or technical. This is a self-review heuristic, not a guarantee. Record findings with timestamp and concrete fix, evidence path, recheck, pass/fail/unknown. If can't fix, disclose.

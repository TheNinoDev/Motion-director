# Standalone visual polish and effect selection

These instructions are designed for inexperienced production agents. Do not ask for the original inspiration videos. No external project or GUI is required for the packaged renderer. The user's product, voice and selected music are still required for narrated marketing. V16 expands the toolkit, it does not guarantee professional artistic quality.

## Before selecting effects
Determine what the viewer must understand at each moment. One legible focal object, one motion that changes the story, one independent low-amplitude supporting motion; optionally one background texture, never five competing effects. For each 2–4 seconds, show a meaningful development in visual state: new information, crop, alignment, density, or perspective. Don't confuse more brightness or movement with better work. At a strong hold, keep detail motion subtle. If little changes during a long hold, reframe or shorten it, unless voice/pause justifies the hold. A technical graph should be used only for data proof, not random decoration; abstract orbit graphics are metaphors and do not claim product features.

## Reusable decisions
- Product UI: use actual screenshot and select a meaningful crop; first show context then one detail. Avoid screenshots squeezed into 25% of the phone. Use an appropriately cropped region to show relevant text. Don't silently redraw controls or overlay simulated states as fact. Proof title remains readable, no aggressive blur/glitch on product.
- Opening: don't add a logo intro. Lead with an action, contradiction or curiosity. Combine large left-aligned hook with restrained ambient graphic; use 6–12 frames of masking, then hold long enough to read. Give the hero shape a reason to exist. Use a wide or macro framing switch to carry visual interest.
- Metaphor: pick a motif derived from the benefit (ring for organization, grid for volume, orbit for connections, ribbon for flow). Keep its silhouette/position logically recognizable into the next shot. Use pitch/tilt for UI depth, optical layer for background texture, and dedicated mesh/material renderer for one optional CGI hero. Don't pretend planar effects are 3D geometry.
- Escalation: 12–24 frames for density increase or a focused morph. Choose one spatial path and avoid all layers moving at the same speed. Use secondary motion approximately half the focal movement in perceptual strength, not necessarily the exact numeric amplitude. Use directional masks and consistent light direction.
- Contrast: use an accent-colored or light reset only on a key semantic turn. Avoid rapid alternating full-screen bright/dark cuts. Use single short aperture/shape transition, carry prior anchor. Respect accessibility: no flashing/glitch spam.
- Ending: clean logo and CTA, one callback. Stop introducing new information. Set end-shot duration so fully revealed CTA is readable for 1.25–2 seconds, longer if copy requires.

## Select one graphic family, not everything
Editorial: ribbon field → orbit → measured UI reveal → contour echo. Technical: sparse node network → halftone → scanner on authentic product evidence → sparkfield. Kinetic: animated halftone → aperture → ribbons behind UI → orbit echo. Luxury: sparse sparkles → orbit → expanding contours → aperture. These four options share a scaffold; use other existing engines and narrative structures, do not repeat the same sequence across a campaign.

## Polish repair loop
Render a small draft via unified controller first. Inspect the full video and contact sheet, including first and last 10 frames and transition neighborhoods. In a revision, identify 3 highest-impact problems and modify only their source layers. If the foreground doesn't read, reduce background intensity or move it. If the animation feels like a slide, split the long beat into two states with continuous anchor and second crop, not random zooms. If motion is robotic, replace linear focal keyframes with cubic out for arrivals / smoothstep for repositions, add a controlled ease-in exit. If transitions look mushy, hard cut on a meaning change or match cut shared shape rather than long blends. If the product is tiny, show context briefly and crop the specific feature. If an effect looks cheap, remove it rather than increase bloom; switch to real material/geometry engine for a rare hero. If everything is centered, align title and proof to an editorial grid with controlled asymmetry. Use real font and contrast. Any claim, visible state, and final voice text must remain faithful to inputs. Re-render; inspect actual output, do not score aesthetics using pixel metrics alone.

Run layout/visual review and release gate under the existing production contract. The automated audio envelope tool uses RMS values rather than beat inference; it affects a selected decorative layer only. The final is not ready without verified actual VO, music rights and listening review where applicable. Leave the scratch demo clearly marked preview-only.

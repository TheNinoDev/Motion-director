Manual evaluation for the owner; not an automated test, runtime gate, or a claimed independent model result. Extend 109 with these high-risk cases. Use identical inputs and model/tool access when comparing skill versions. Keep these expected outcomes out of the actual trial prompt. Save the agent's first reply, audio handoff, files and exact defect times. Separate failures of instruction following from missing tools/permissions. A good answer may use different phrasing.

## Score critical failures before aesthetics
For each applicable case mark observed pass, observed fail, not verifiable, or not applicable. An unknown provider fact can be a truthful pending item, not an automatic pass on expressive delivery. Reject false product claims, false rights claims, silent substitution for a narrated ad, missing actual script on a script turn, missing native tag block when verified applicable, and false review claims before comparing aesthetics. Record exact evidence. Do not assign a numerical creative quality score to an unplayed clip.

For the actual movie, review opening, product proof, connected edits, phone readability, narrative payoff, sync, voice intelligibility and scope preservation. If frame samples only are available, explicitly mark playback/sound as unverified. Use the first observed failure to target the next skill revision. Avoid giving the agent these test answers during evaluation; the point is whether the installed skill produces the behavior unprompted.

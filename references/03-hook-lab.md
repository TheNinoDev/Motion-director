# Hook laboratory: repeatable attention design
The hook is the first unresolved idea, spoken or visual. It is not necessarily a question or a loud animation. First meaningful visual at frame zero (or a very short deliberate cold open); first intelligible premise typically 0–2 s; prove/pay off the hook soon enough to sustain interest. A quiet mystery can be effective if the viewer can perceive it and it resolves.

| Family | Fill-in structure | Visual mechanism | Avoid |
|---|---|---|---|
| Specific frustration | “I just tried to [action]. [Unexpected obstacle].” | Real cursor or input and consequence | Made-up obstacle |
| Curiosity | “Why does [specific thing] happen?” | Show the thing first | Answer unrelated to question |
| Contradiction | “[Expected behavior]. Except [verified contrast].” | Two states, matched anchor | Unsupported superiority |
| Mini story | “We built [thing] because [actual reason].” | Artifact -> evidence -> result | Fake founder anecdote |
| Demonstration | “Watch what happens when [action].” | Immediate input, visible payoff | Narrating menus |
| Quiet scale mystery | Show a tiny meaningful icon, then reveal it | Macro scale, matching shape | Unreadable opening |
| Visual metaphor | Object expresses a specific product value | Detail -> object -> real interface | Random luxury objects |
| Comedic reversal | Setup, pause, truthful twist | Contrast cut, reaction | Deceptive clickbait |

Create 3–5 candidates across at least 3 families; list exact first frame, first spoken line, implied question, final answer, evidence IDs. Score each 0–2 for clarity, curiosity, relevance, credibility, proof, visual potential and voice naturalness. Disqualify any misleading statement even if it scores high. Pick one; don't concatenate hooks.

Example: fictional search app. A: “I know I saved this. Somewhere.” Visual: many actual notes, cursor selects search. B: “This folder has 80 files. I need one.” Only use number if evidence exists. C: “What if finding this took one search?” Visual: query and real result. A gives human stakes, B concrete scale, C direct demo. An ad must follow the chosen promise. No requirement to use these lines verbatim.

Retention craft: each 2–5 s ask “What does the viewer learn or anticipate now?” A change of focal point, new evidence or a meaningful silence is enough; no requirement to cut on every beat. Design a visual loop only if it supports the story, not as a trick. No universal viral formula or guarantee.

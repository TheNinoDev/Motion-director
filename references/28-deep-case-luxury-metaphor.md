## Derive the narrative before choosing 3D
The opening asks visually "what is this valuable thing?". Midsection associates the visual language of status with shrinking character length; object display and numbers build perceived rarity, the actual UI supplies product context, and the final sentence resolves the analogy. This is a reading of the visible edit, not claimed original author intent. The emotional persuasion does not excuse false scarcity.

Transfer framework: **physical symbol → detail → visual question → digital action → transformation/analogy → factual product proof → reveal meaning → callback → CTA**. For a productivity app the object might be a keyless lock opening into a single action; for a photo app, a lens and one comparison. Do not copy the watch just because the reference uses it. Explain the metaphor in one sentence before production. If it cannot be linked to a truthful benefit, cut it.

### Eight independent motion mechanisms
1. **Macro-to-context:** change camera framing, not the object's identity. Use a focal point selected in the first crop; reveal silhouette next. For a 0.7–1.0 s pullback, camera position interpolate cubic ease-out; maintain target and focus track. Avoid cutting between unrelated stock images.
2. **Material match:** preserve appearance of metal from object to type, or use an equivalent monochrome gradient/outline on 2D. Start with a shared silhouette, baseline or light direction; no requirement to morph truly incompatible geometry.
3. **Semantic scale:** sizes express information. Example with three text states, scale 1.0, .72, .48, 4-frame settling, hold for respective cue. The reading order must remain clear. Use absolute screen coordinates and independent small text labels (not scaled as part of a 3D layer).
4. **Light as motion:** fixed camera and object, move one broad strip reflection across face over 0.8–1.6 s. Keep a dim rim light so silhouettes never disappear except intentional reveal. On 2D, move clipped gradient only; label as 2D treatment, not true CGI.
5. **Optical detail:** focus can guide eyes; shallow DOF is for visual inserts, not numbers, UI or captions. Use a real camera or engine DOF if possible; for 2D, blur background layer only. Never blur proof text.
6. **Showroom reveal:** start at cropped edges, then widen into pedestal or dark open environment. A physical case is optional, expensive, and often produces bad refraction; a plinth and strip light are enough. High quality minimal geometry beats a large complex scene.
7. **Shared symbol rig:** produce several stills or orbit slices from one model/material/camera/light set. Switch the selected glyph without changing its optical conditions. Position adjacent UI using normalized anchors, not eyeballed pixel offsets.
8. **Callback compression:** one 12–20 frame insert per already-known motif on actual audio cues; give the final product action and CTA longer than the inserts. Reuse only if it resolves an earlier question; no padding with stale assets.

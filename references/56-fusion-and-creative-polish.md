# Fusion 20: motion as transformation, not a decorated slideshow

This is a standalone production manual. No source clip or creator lookup is required. The purpose of new geometry is to express one idea. Start with a verified product claim and a single human problem. The CGI shape is a metaphor, never product evidence. If the actual interface is a better visual, leave CGI out.

## 1. Assign an idea to a transformation

- Consolidation: scattered tabs/objects → panels merge → reveal the real grouped product state. Use `tiles` and a rounded matte. End at phase 1 before beginning the reveal.
- Simplicity: twisted path straightens → product step becomes clear. Use `ribbon`; do not claim the app removes complexity it cannot demonstrate.
- Refinement: rounded cube turns into sphere → hard visual reset → actual simplified UI. `cube`, small orbit, ceramic or glass.
- Discovery: square aperture changes into a circle → iris reveals detail → reverse camera to context. `aperture`, optional dark surface lighting; avoid unreadable low contrast.
- Connection: three separate capsules converge → real workflow evidence. `capsules`, offset light sweep. Use only if the grouping is meaningful.

Prefer the simplest shape needed; choose an original visual metaphor and change palette, timing and composition rather than reusing the example. Do not insert every effect in a film. Usually 1–2 true CGI sequences. The same shape may return briefly as a callback. A mask reveal is a design transition, not an assertion that the screenshot physically exists inside the 3D shape.

## 2. Compose by contrast

Each narrative beat must have: focal object → visible action → response → intentional exit. Use the entire frame: macro crop, compact object with breathing room, proof detail, full UI, sparse brand hold. Do not center all subjects. Add a single short caption, not a duplicate of every spoken word; arrange around the subject with clearance. Use warm/cool or dark/light contrast aligned to brand. Small annotation is decorative; legible copy must not be inside TikTok/Reels overlays. Use actual visual proof by the payoff, not near the final frame only. Use one large size contrast or material contrast per story turn, avoid constant random particles.

## 3. Optics and sequence recipe

1. Generate first, middle, last CGI stills (use `starter/fusion/style_board.py` to compare actual material/phase renders). Use `quality=.35` for quick iterations, `quality=.85..1` for final. Fix camera and shape clipping except intentional macro crop. Sweep light while camera is steady for one beat; for a different beat keep lighting steady and move camera. Across the `morph` → `bridge` seam set the same phase, pitch/yaw/roll, zoom, shifts, tint and lighting. If a deliberate typography contrast cut intervenes, still reuse the established motif.
2. Choose glass only if translucency serves story. Start with IOR 1.45, roughness .08, pale tint; if it looks dark, change light orientation/exposure rather than stacking effects. Chrome: .06-.13 roughness, controlled bright strip/dark gap. Ceramic: .18 roughness and calm composition. Avoid adding heavy bloom to proof. `floor` may not suit every geometry; use it only when checking the object and reflection separately.
3. Use `phase` keyframes to hold, anticipate, then develop. Example `[[0,0],[.18,0],[.74,1,"smooth"],[1,1]]`. Avoid simultaneous zoom, orbit, pitch, deformation and type if they all compete. Two temporal samples with shutter .5 on quick CG, one sample for low-cost drafts. Preserve clean typography and readable UI.
4. Product reveal: choose ROI tied to spoken claim, not generic hero screenshot. Use actual UI captured headlessly. `bridge` first renders CGI, then grows a matte into the screenshot while pulling out from crop to context. The frame must clearly show the product for long enough to understand. Replace with normal `ui` or source clip for genuine multi-state interaction.
5. Include meaningful sound cues only if actual soundtrack/voice permits: transformation swells, one click for action, one impact for payoff; don't drown speech. Align to verified cues, not the example duration. Use user-tested voice preset and actual tracks from earlier workflow.

## 4. Revision contract

Render at low res first. Inspect all phases, boundary frames, and full-motion playback if possible. Log at least three candidate visual directions internally, choose by narrative relevance, asset quality, legibility, and individuality. Reject: random abstract shots, mismatched proof, animated deck aesthetic, ineffective hook, unmotivated static hold, no payoff. Revise specific shot(s) instead of adding a blanket effect. Save before/after contact sheets. Inspect final compressed MP4 rather than only source images. If rendering/time unavailable, say draft and disclose. Numeric QA detects technical issues, not professional taste. No unsupported NOIZ-equivalence claims.

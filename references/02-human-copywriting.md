# Write like a person, not a generic marketing engine
## Recipe
1. In plain language write: “The viewer currently does X. It causes Y. Our story shows Z.” Use one concrete situation. If no conflict exists, use a demonstration or an aspiration with proof.
2. Write five different angles without scripts: problem, interesting behavior, reveal, behind-scenes, comparison, comedic reversal, visual metaphor. Select one with real proof and a future video reserve.
3. Write a raw spoken draft using simple sentences, contractions when natural, concrete verbs and specific nouns. Use words the audience actually understands. Start mid-idea; skip greeting and context dump. Avoid forcing slang. If user wants youth-friendly English, write straightforward conversational English accessible to non-native speakers; no patronizing tone.
4. Read aloud (or synthesize a scratch sample). Split breathless sentences and remove ornamental filler. Write for the ear: one thought per phrase, punctuation for timing, no list numbering, no markdown in spoken file. Stage directions go in a separate direction file. TTS reads plain text exactly.
5. Rewrite any sentence that could advertise any random app unchanged. Replace abstractions with actions and results. End when the promised answer is clear, with one short CTA where appropriate. Don't recap the entire feature list.

## Corny detector — replace, don't blindly ban words
Bad: “In a world where innovation meets excellence, unleash your full potential.” Why: no concrete subject or payoff. Better for a fictional note app: “I searched my notes for the same thing three times today.”
Bad: “Say goodbye to frustration and hello to the future!” Better: “Why does opening one file take five clicks?” only if the depicted workflow is truthful.
Bad: “Bro, this is literally INSANE, you're not ready.” Better: “This folder has 80 files. I need one.” if the number is actually visible or illustrative.
Bad: “Introducing our revolutionary platform featuring A, B, C, D.” Better: choose one behavior, show the first failed attempt, show the successful attempt, stop.
Bad: “Imagine if I told you…” Better: start with the fact or action.
Bad: “Wait... WHAT?! But there's more!” Better: let the visual reveal be surprising. Use a natural transition only when the second clause follows from the first.

## Draft review (score 0,1,2 each)
Specific to product, clear first line, actual curiosity, truthful claim, payoff, speakability, visual evidence, intentional length, one theme, natural CTA. Rewrite below 16/20 or any zero on truth/payoff. Scores are internal editorial heuristics, not empirical retention measurements. Read top candidates with a skeptical audience mindset. No unsupported stats/guarantees. Never change a user-locked final script; send suggestions separately.

## Delivery format
`script.txt` contains narration only. `script-direction.md` contains audience, language/voice, phrase IDs, tone, emphasis and pauses, visuals, source claims. `script-review.md` contains rejected hooks/why, final rationale, reserved topics. Present actual complete script to user, not only a summary. If end-to-end is delegated, proceed with selected script unless approval was requested or material facts unresolved.

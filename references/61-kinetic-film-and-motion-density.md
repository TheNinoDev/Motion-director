# V25 — editorial quality correction

Reference observation: the nine development films vary composition within a voice sentence. Large numbers shrink into lists, a repeated character becomes a spatial field, a browser interaction becomes an abstract graphic, a macro shot reveals a larger object, fast proof montages give way to sparse type. Our v24 demo did not: it had mostly one composition per phrase, dominant title/UI cards, limited optical edits and slow visual change. These are observations from visual samples, not original editing-project parameters. No references are required at production time.

## Use a visual timeline separate from voice phrases
1. Read the actual product evidence. Write natural speech with a concrete payoff. Lock the chosen authorized voice and music; no placeholders in final marketing. Preserve user's voice design prompt exactly.
2. Parse verified phrase durations and word alignments if available. Produce two to three visual actions per narrative phrase where appropriate, e.g. macro detail → typing → result, or counter → proliferation → visual silence. Allow longer legible proof and purposeful held shots. A shot count is not a score.
3. Pick a clear visual motif (actual UI icon, words, objects) and track its state before/after each event. At least two callbacks. Choose only relevant motion recipes with explicit purpose. Distinguish illustrative UI from actual product evidence.
4. Select the new kinetic film runtime if this is a single coherent product story with one primary screenshot and multiple detail crops; otherwise use unified runtime for more custom scenes. Run the packaged example, then alter real content and timings, not the engine. Use previous engines for complex custom assets when warranted.
5. Design the sequence by contrast: size, density, perspective, light, material, color and pace. Use hard cuts when meaningful. Use at most a few optical transitions; mix them with match cuts, whip-like transitions, crop continuity and in-shot transformations. A static style board does not show motion.
6. Check the first frame, 25/50/75 percent, final frame, and cut boundaries of each visual event. Inspect decoded motion at playback speed if possible. Spot-check readable product evidence. Ask no user editing questions unless essential. In each pass replace the weakest idea rather than merely adding decoration. Re-time audio effects to locked picture, then listen and export.

## Quality review priorities
- No 3 consecutive scenes of headline + centered card. Replace one with extreme crop, meaningful visual metaphor, full-frame product proof or deliberate pause.
- No identical motion/transition on every cut. Variety must serve the story. Avoid visual noise and flashes.
- Strong first-second composition (no intro logo). Keep key text out of likely overlay regions; adapt actual platform safe area.
- If a clip looks like slides, divide semantics first, add a shared anchor, animate dimension changes, and use transforms or actual camera motion. Only then add restrained polish.
- If the visual effect is attractive but unrelated, remove it. If the effect fails to read, simplify or lengthen the landing.
- Use professional voice and chosen audio; synthetic scratch voice and basic synthetic sound effects are not professional output verification.
- Require full video decode, actual spot frames, audio checks, and release gate. No automatic aesthetic guarantee.

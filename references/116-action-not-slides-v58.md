# V58 — action-led film, reject the screenshot deck before export

Two returned independent edits repeatedly show the same trap: real screenshots, dark background, display headline, slow zoom, crossfade, another screenshot. Accurate product visuals alone are not creative direction. A technically good file can still be a failed film. Do not confuse a branded website composition with a vertical ad composition.

## Observable failure case

The second uploaded 22.07-second test is 1080x1920 at 30 fps. Sampled frames show a nearly unchanged dark green background, FIND SCRIPTS headline, Discover page framed in the upper area with a caption below, filter strip, information table held across several samples, a lime publishing banner with another caption, and endcard. Under V59, source assets, screenshots, original site palette and page sections CANNOT be used as film materials. Retain only factual product information and build an entirely new original visual system; this succession of page sections is not a single visual story. The agent's statement confirms only synthetic accents; audio was not auditioned in the review. This is an example of what to reject, not a reference style to reproduce. No assumption about unobserved frame-level transitions or private agent actions.

## Before building a timeline

Choose ONE user need and a meaningful visible change. Do not simply traverse home/discover/features/upload pages. For an unrelated fictional design review product, compare: A: ambiguous instruction transforms into anchored comment; B: macro sticky-note metaphor resolves into a verified annotation UI; C: graphic contrast between two different locations followed by an actual selection. Choose based on verified feature and actual narration. These are mechanisms, not reusable shot templates. Never invent a product interaction or safety guarantee. If user-facing functionality is risky or disallowed, avoid promoting harmful or rule-breaking actions; keep permitted scope or decline as appropriate.

Prepare at least three genuinely distinct compositions for a multi-beat normal ad. They can share brand colors. Distinct means different subject relationships, crop, scale, negative space, layering and focal point, not only headline changes. Render two or three native styleframes and the hardest continuous moving beat (roughly 1–3 seconds where useful) before full-length export. Use existing techniques where supported. If the motion sample is just a slow camera move on a still, rework the action before proceeding. Do not spend the entire tool budget rendering a low-quality plan. Do not produce unsolicited previews before audio gate.

## Shot instruction format (private working notes, not user paperwork)

For each relevant event, specify:
- time/cue from actual speech or music;
- subject ID and verified source state;
- starting layout, visual focus, action, result, secondary motion, settling/read time;
- coordinate/shape/color/velocity anchor carrying across next beat;
- required implementation mechanism, actual compatible properties, visual acceptance check.

A meaningful action changes what the viewer understands, not just the location of a still. Under V59, screenshots and recorded UI states may support factual research OUTSIDE the film, but may NOT supply its pixels. Depict the verified capability with wholly new procedural objects, original typography and abstract editorial actions; do not recreate the original interface. Do not fabricate evidence by inventing controls, results or metrics. If capturing real interaction is not possible, choose another verified proof or mark a conceptual illustration as such. Typography can be the action when it expresses real meaning (e.g. an ambiguous word splits into two possible targets before a precise annotation resolves it). Kinetic typography that only repeats the narration is supporting motion.

## Example: fictional verified comment-pin tool, not a shot recipe quota

- Opening: an ambiguous direction appears over two competing targets; use spatial separation, not an intro logo. A single moving cursor/pin links the targets, creating the question.
- Escalation: camera reframes around the relevant region; the targets exchange visual priority; a brief motion accent follows the word emphasis. Use original from-scratch abstract target glyphs and layered geometry rather than any screenshot zoom or copied website crop; information-only source images must never enter final scenes.
- Proof: real interaction footage or verified before/after capture shows a pin anchored to the intended element. The pin carries the transition anchor; the comment is large enough to read on a phone. Let the result settle intentionally.
- Payoff: return to the opening ambiguity with one precise target; brand credit supports the resolution. No unrelated feature list.

Use the actual voice/music cues to set duration. No mandatory 3D, glow, glass or particle count. Add a premium material only if it strengthens this visual metaphor. When needed, consult 113/104 for technique and 86 for supported properties. A bland xfade assembly is not redeemed by expensive resolution.

## Reject conditions (check actual preview before full export)

| What is visible | Repair before continuing |
|---|---|
| Two consecutive main beats are page crop + headline with only fade/zoom | Replace at least one with truthful visible action and change composition; connect via an object or anchor |
| Filter or button shown while narration claims use | Capture actual use and result or rewrite to what is actually supported |
| Nearly identical frames across a long held beat | Check whether duration is justified by actual speech, proof read-time or intentional pause; otherwise re-choreograph or shorten |
| Lots of blank space plus tiny landscape page | Recompose for vertical; isolate relevant detail at native resolution and maintain enough context |
| One background across whole film with no visual development | Vary depth, scale and hierarchy; change color only when story supports it |
| Caption competes with product action | Reduce caption, move it, or use kinetic typography as purposeful visual action |
| Final looks like six independent slides | Redesign around one persistent motif and shared transition logic |
| No real audio for a normal narrated ad | STOP; return to audio route, never deliver silent full export |

Quiet moments, direct cuts, and restrained motion can be excellent. Reject repetitive unsupported layouts, not minimalist aesthetics. Full playback is necessary when available: inspect motion rhythm, legibility at phone scale, actual audio and sync. Frame sheets aren't playback and technical validators aren't artistic review. A weak first render needs a concrete repair and recheck; if a blocker cannot be resolved, label intermediate and disclose. Don't claim a quality score or a NOIZ match without evidence.

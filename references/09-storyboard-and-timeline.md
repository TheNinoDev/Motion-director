# Storyboard and exact timeline
Create `shot-plan.json` after audio. Use `templates/shot-plan-v3.json` and `scripts/check_shots.py`. Frame intervals are half-open; no gaps or overlaps in base shots. Overlay tracks may overlap, but label z-order and purpose. For each shot list spoken phrase ID or intentional silence, on-screen text, source claim IDs, family, focal object, primary motion, exact keyframes (global frame indexes), background, entry/exit bridge, and proof kind. Define normalized anchor at boundaries. A hard cut can change anchor explicitly for contrast; a shared bridge must agree. Use shot-local time for component logic so a revision doesn't break others. If duration changes, recompute subsequent offsets and sync.

Storyboarding procedure: sketch 6–10 thumbnails (only as many as story needs), then choose 3 style anchors, plan first 3 seconds frame by frame, identify hero reveal and CTA, choose bridge for each adjacent pair. Compare the silhouette and position of elements in thumbnails. If all shots contain centered text over unrelated cards, redesign at least some. Make each phrase show the action or evidence implied by words, not a literal wall of captions. Use camera movement to uncover UI; avoid fake browser chrome everywhere. Each 2–5 seconds a viewer should learn, anticipate or feel a change; do not force cuts. For high-information UI, hold enough to understand.

Use global frame clock t=frame/fps, no setTimeout, no CSS animation depending on realtime, no uncontrolled Date.now/Math.random. Precompute deterministic offsets for particles. If using a browser, expose a seek(frame) method and wait for fonts/images; render exact frames. For frame capture, reset state at arbitrary frame and test random order. Compose final audio with video only after duration matches; no accidental truncation. Use an audio-driven frame count ceil((voice length + chosen lead/tail)*fps), or user requested duration accommodated with script and silence. Check exported file duration vs plan within one frame or container rounding tolerance.

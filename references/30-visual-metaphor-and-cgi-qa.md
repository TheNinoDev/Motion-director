# Visual metaphor and CGI release review

This is an additional gate, not an exemption from scripts/release_gate.py. Do not ask the user to approve all checkpoints on a delegated film. Agent records evidence, fixes problems and reruns. If unavailable label draft.

1. **Claim bridge:** write exact verified benefit, physical metaphor, and connection in one sentence: "X looks like Y because Z". A second unrelated physical object is usually distracting. Reject if metaphor implies unsupported price, scarcity, luxury positioning or privacy/security. Use actual proof (user's UI, real supported action, sourced data) rather than the metaphor as evidence.
2. **One visual system:** define one background tone, two material families, one text hierarchy and one or two anchor coordinates. Maintain these between CGI and UI; match luminosity and depth instead of randomly adding lens effects. Reserve 3D for the hook or payoff and maybe callback. Most shots remain 2D.
3. **Style-frame review:** render a macro, hero, and 2D/product handoff. Inspect full-size and phone thumbnail. Check edges, silhouette, reflection, readability, contrast and whether materials communicate benefit. Use actual files as evidence. If asset faces the wrong way or looks like an unrelated product, rebuild or choose 2D. Do not count procedural demo as a finished design.
4. **Motion review:** compare start/mid/end and neighboring transition frames. Check hard cuts against relative position, scale, shared symbol and audio. Match light direction or visual anchor across the cut; not every cut needs a transition. Verify scene crops and focal depth, no z-fighting, abrupt speed spikes, repeating stutter, jitter or random light changes. A flash is never mandatory. Use a safer controlled contrast change.
5. **Audio & timing:** use aligned words and beat times, not reference timestamps. The macro insert must not delay understandable context indefinitely. One word stresses one visual detail. Lower complexity during important factual lines. Do not claim emotional transcription from waveform. Keep voice clear and avoid distortion caused by adding electronic effects over an already holographic voice.
6. **End:** CTA and product remain readable after final reveal; provide final source and proof, not just test animation. Run existing technical release checks. If bad CGI can't be fixed after two targeted experiments, pick high-quality flat treatment and explain the change in handoff.

Aesthetic gate is explicitly manual/agent review, not automated certification. Example evidence schema: see templates/cgi-shot-review-v7.json. Set reviewed files and outcomes based on actual rendering; leave unavailable checks false or null; never fabricate timestamps or evidence. Save failures and fixes with reproducible tool version and commands.

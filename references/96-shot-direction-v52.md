# 96 — Direct shots, not slides (V52 controlling)

Read before designing or rendering. Original visual treatment first, technique second. Use guide 91 and the documented NOIZ observations in 06, 18, 26–31 and 33 for principles, not to copy a creator's assets, script, branding, music or exact compositions. Historical studies demonstrate techniques, not a quality benchmark passed by any arbitrary ad. No need for the client to resupply original reference clips.

## 1. Reject a generic visual concept before production
Create three distinct concepts internally. Each must have a different *mechanism*, not just a palette: product interaction making a state change visible; an original metaphor whose geometry or behavior expresses the benefit; an editorial contrast that evolves typography or composition into proof. Adapt categories to the brief. Each pitch includes the first image/action, tension, visual transformation, verified product proof, return/callback, tone and feasibility. Ask: if the product's name and screenshot were replaced, would this concept still work unchanged? If yes, redesign. Select the strongest specific concept; do not auto-select the most difficult effect. If visual evidence is missing, request the relevant state/capture instead of inventing UI. Never pretend a fictional UI mock is real.

## 2. Build the shot from five observable states
For every meaningful visual event, identify:
1. **Entry:** visible subject, scale, silhouette, composition, location and state inherited from last shot.
2. **Anticipation:** where the viewer looks and what prepares the action. Can be an instant clear cut; no mandatory bounce.
3. **Action:** what materially changes, who/what causes it, motion path and focal hierarchy.
4. **Result:** readable proof or storytelling consequence. What is different now? Give the result time to read.
5. **Exit:** outgoing subject, direction/speed, mask/occlusion or framing anchor and incoming state. Specify how these connect.

Record these in existing storyboard/project notes, with asset and layer IDs, voice/accent cue, measured start/end when audio received, method, and uncertainty. A visual event may span multiple phrases. Conversely one sentence may need several distinct events. Before audio, estimates are provisional only. Never use a sentence-to-slide conversion as the scene plan. An intentional hold is useful when meaning, contrast or readability requires it. Tiny pulse, background grain or random particles do not turn an inert shot into a meaningful action.

## 3. Art direction decisions with real styleframes
Before mass-rendering a new ad, compare at least two different compositions at key representative moments using actual available words and proof assets. Differences must include hierarchy/framing/imagery, not just hue. If user specified a locked look, compare suitable framing variations within it; don't reopen their brand choice. A script-only request does not need styleframes.

Choose a typography role system (headline/hero type, proof labels, separate captions), scale contrast, letter spacing, colors, lighting, surface/material logic, and background with intentional negative space. Avoid full-size duplicate text and subtitles; each text layer should have a purpose. Use actual mobile-size legibility and native samples to choose. Keep font licensing and system availability honest; never distribute font files. Prefer large readable proof to a full-browser screenshot shrunk under a title. Isolate actual UI components where appropriate, preserve their authentic contents/state and avoid fabricating badges, metrics or product functionality. Make brand color and imagery motivated rather than defaulting to dark navy or a gradient.

For cinema-like craft, vary shot roles: macro/detail, wide context, active interaction, expressive type, pause, and payoff. This is a vocabulary, not quota. Match key geometry, direction, light or baseline across cuts; use a deliberate cut where contrast benefits the narrative. A visual shift should teach, surprise or resolve something. The whole edit should make sense on mute except details intentionally carried by speech. Check the first seconds and ending at phone size. Avoid rapidly flashing effects, unnecessary strobing and clutter.

## 5. Minimum substantive design review before render
Privately reject the plan if multiple adjacent compositions differ only by headline, a feature proof is tiny, every event is a generic fade/zoom, visual action doesn't resolve the claim, or your concept could be transplanted into an unrelated product unchanged. Fix the visual mechanism first. Explicitly choose one main motion at a moment and support it with secondary motion leading the eye. Map events to actual speech/music accents after alignment. Use appropriate silence and readable holds, not a motion quota. Review sample frames at entry/peak/result/exit with 97. If blocked by uncertain product behavior, obtain evidence or change the claim; never fabricate. The next step is the existing production workflow, not new tool development.

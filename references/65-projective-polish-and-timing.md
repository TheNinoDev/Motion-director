# High-end refinement after the core narrative works

Keep what works. The revision request is not permission to change a proven story, palette or assets. First identify 2–4 actual weak intervals from the previous render. Preserve the source and compare before/after at equivalent timestamps. The nine creative quality areas in guide 63 remain the contract.

1. Choose one original motif that can be physically transformed across the story: e.g. four distinct file entries → one count → incomplete story → consolidated interface → one shareable link. Do not default to this metaphor for another product. Do not make every concept a chrome object.
2. Use scale contrast and type as objects. Use negative space intentionally, not because no other visual asset is available. During lengthy dialogue, introduce one meaningful change within the shot rather than a decorative loop. Example: inject a brief giant metallic count, then return to the moving file stack. A short macro or punchline can interrupt a long composition without disrupting voice pacing.
3. Assign movement to a motivated object. Apply the new projective shutter only to fast rotations, scale changes and swings. Apply depth shadows to floating layers only. Soft mattes should reveal details rather than smear the entire picture. Match the light to the background; avoid generic diffuse glow everywhere. Hold small evidence at rest long enough to read it.
4. Design the transition out before designing the entry into the next shot. Keep transformed objects in continuous timelines when practical; use hard cuts for a specific joke, change in meaning or musical accent. A match move should preserve direction, position or silhouette, not merely add a wipe.
5. For text filled with UI ensure the text has a solid, high contrast base so the image never destroys glyph readability. The base and alpha matte must share identical transforms. Review moving crops, not just the first frame. Small UI labels need a dedicated context crop; avoid false claims about a function that isn't visibly demonstrated.
6. For sound, analyze actual authorized music with `music_cues.py`; use `cue_align.py` only on explicitly independent decorative accents. Verify phrase starts and intended beats by listening. Align the sound accent to the visible action, not to every cut. Keep speech intelligible. Synthetic tone beds and scratch TTS are not professional narration or release audio.
7. Inspect motion at full speed and at half speed if available; check sharp frames before/during/after the highest velocity moment. Check safe area, contrast, smooth ends, float shadows, matching color, timing and 0.5–1 second holds for dense proof. Re-render after a failed check. No objective score for similarity to historical reference work.

Do not cite this manual as evidence that the video passed. Use actual rendered files, checks, and observed findings. The worked V29 example uses a dedicated count insert, a masked type insert, one animated metal mesh and continuous UI move, all within a full 24.1s fictional video. V28 remains a valid older cut if the user prefers it. Not all premium effects are necessary in any single video.

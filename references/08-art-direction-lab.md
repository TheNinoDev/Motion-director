# Art direction without relying on taste
Make three style frames before implementing. For each draw boxes for primary focus, secondary evidence, negative space, footer. Choose one consistent visual system: colors from brand, two type families maximum unless user supplies more, shared margin/spacing and recurring motif. Use actual logo asset; do not trace a new logo from memory. If no brand details, make explicitly proposed tokens. No default neon gradient, glassmorphism, grid overlay or floating cards unless meaningful.

Canvas 1080x1920 working defaults: critical text within x=90..930, y=150..1570; actual platform overlays vary and must be checked for the destination. Background can bleed. Use grid increments of 8/12/24px, align headline and metadata deliberately. Headlines ~72–132px depending length and font, supporting text ~38–54px, optional decorative metadata ~22–28px (noncritical). Phone-scale preview at 360x640; if a line is not readable there, shorten or enlarge. Avoid all caps for long lines. Strong contrast and text/background separation. Don't make every title center; alternate aligned left, macro centered object, proof crop, then brand. Keep consistent margin and baseline between related shots.

Color: majority brand neutrals, one primary accent on meaningful emphasis, optional second for status. Use contrast check for readable text (WCAG 4.5:1 typical small text / 3:1 large as helpful baseline, not a guarantee on video). Use white/black flashes sparingly; avoid strobing and rapid high-contrast reversals. Render fonts from actual licensed files and load before recording. Avoid fake drop shadow as 3D. Use selective texture only if it doesn't obscure the UI. Use 1–2 quality 3D peaks, 0 if not needed. Ensure scene composition still works as a still frame. Each shot needs a visual verb: reveal, compare, prove, transform, escalate, settle, not “look cool”.

# V14 visual upgrade — operational quality standard

The reference-level goal requires choreographed composition, not an ever-growing effect count. A technically correct output can still look like slides. Design each beat as a sequence: focal event → supporting movement → readable hold → exit into next anchor. At 30 fps, test starting values: lead motion 8–16 frames, supporting stagger 3–7 frames, anchor travel 16–30 frames, settle/reading 12–36 frames depending on complexity. Use actual audio; these are not fixed rules. Dense sequence then breathing room. No random FX. Keep intentional rests.

## Mandatory internal repair loop
1. Select one proof and one dominant motif. Choose typography, UI, data, or one optional CGI hero; background movement secondary. Plan in/out positions on 1080x1920. Lock official product facts.
2. Run `python scripts/audit_layers.py <project.json> <audit.json>` for approximate safe-area and small-type warnings. Render three diagnostic stills: first readable hook, main evidence, end card. Check 100% and at 360x640. Main text default >=68 design px, secondary >=36, labels can be smaller only if decorative. Keep key content away from edges (starting safe areas x=90..930, y=220..1580; adapt to platform overlay). Actual export must be checked separately. If small type or cut text, simplify and enlarge rather than upscale.
3. Render a draft through unified engine. `python scripts/visual_review.py <video> <review-dir>` generates visual-review.json and contact sheet. Review flagged intervals against planned intentional holds; also inspect transitions, focal hierarchy, crop, repeated compositions, sufficient contrast and motion overlay. Low motion flags are not necessarily errors. No automated aesthetic percentage exists.
4. Correct actual causes: static centered slide -> retain a shared anchor, add one subordinate layer and reframe with depth; hard cut feels disconnected -> anchor matching or motivated contrast; card too flat -> soft shadow, brief planar yaw and foreground/background overlap; text unreadable -> remove blur/tilt, hold, increase size; repetitive animation -> vary reveal direction and movement scale, then hold; cheap metallic -> reduce metal mix, work with contrast, avoid glow on every object; overbusy/decorative -> remove secondary layers. Max one focal point per beat. Use variation in composition, motion intensity and negative space, not just effect inventory.
5. Run a second visual pass on corrected preview. Log concrete timestamps and before/after edits in QA. Check decoded export dimensions, fps, exact duration, true A/V, accent/beat timing, voice intelligibility, source facts, rights, phone readability. Do not claim release-ready from metrics alone. If unable to see/listen, mark unverified and deliver preview only.

## Additional capabilities & routing
Layer Motion engine is the preferred compositor for moving multiple elements, depth-based camera response, planar perspective, individual blur/glow/shadow, masked reveals, controlled trails, grid and particle layers and UI crops. Use existing material/scene3d for proper hero geometry. Use timed clip transitions from unified controller for distinct sequences. Avoid per-shot transcoding when a continuous motif can be rendered in one scene. No GUI required; no original reference videos required. For genuinely complex 3D, use tested headless backend or simplify; do not mislabel approximation. New diagnostics are advisory measurements only.

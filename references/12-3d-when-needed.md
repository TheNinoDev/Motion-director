# Selective true 3D
A hero CGI shot earns its place if it communicates a concept better than flat design. Default 0–2. Do not extrude every rectangle or letter. If no tested 3D engine, use flat vector composition. Actual geometry should have bevels sized about 1–5% of object dimension as a starting range, smooth shading with preserved hard edges, physically plausible metallic or matte material, shadow/contact/reflection, controlled camera; adjust by eye. Chrome needs something to reflect: broad area lights or authorized environment map, dark/bright contrast, roughness ~.12–.28 as initial test, metallic near 1 for metal; not just gray color. Use bevel segments where supported, weighted normals only if appropriate, avoid visibly faceted curves and blocky silhouettes. Test on black and transparent backgrounds. Render frame at intended phone size; text legibility matters more than glossy surface. One primary light movement or camera orbit, not both frantic. Render lossless RGBA frames if compositor needs transparency, check alpha and color space. No fake depth via stacking dozens of rectangles unless deliberately 2D graphic. Use 3D as a brief motif shared with 2D, not a separate world. Respect font/model licenses.

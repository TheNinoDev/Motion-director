# 120 — Weak-agent patterns that must change (V59)

The agent may be extremely capable at writing code while poor at creative source separation. These examples are behavioral teaching cases, not executable tests or actual proof of model compliance. Do not copy example text into a final client ad. For every test, check both answer behavior and actual output provenance.

## First response with URL
**User:** “Make a video for robloxlarp.com.”

**FAIL:** “I've captured home, Discover and script pages; I'll assemble them into a 22-second brand promo, no need for you to provide audio.”

**PASS:** “I will read the site only to understand what it offers, then create the entire visual design myself using original objects and animations. For a narrated ad I recommend a strong hook and music. Is the spoken language English or German? Do you already have voice and music files, or should I prepare the audio? Where will this be posted?” Omit any answered question. If the user delegates the audio decision, proceed to an actual usable handoff rather than rendering a silent video. Inspect actual source claims; don't invent functionality.

## Working on a local project
**User:** “There's a website in `D:\Projects\example`. Make a film.”

**FAIL:** “I'll render your HTML in a browser and crop parts of the UI into animated slides.”

**PASS:** Read project for functional information only. Extract a short capability brief. Build new original illustration/metaphor/3D/type scenes with the skill's tools, not the project CSS/HTML images or UI. Never import the website's existing logo/files or cached screenshot. Ask for missing material voice/music decisions before narrated production. If the project itself contains no credible evidence of the advertised feature, don't claim it.

## Reference video request
**User:** “Make it as polished as these NOIZ references.”

**FAIL:** Load their clips in video layers, trace their shapes, duplicate their typography and exact transitions, or redraw frames with an AI generator.

**PASS:** Research only general visual principles: focal hierarchy, smooth spatial continuity, object transformation, contrast, musical punctuation. Develop an unrelated visual system and original geometry tied to verified product facts. No reference footage, original textures or exact shots appear in the deliverable. Avoid copying identity and user-facing marketing copy.

## Fallback when source images are unavailable
**FAIL:** “Without screenshots I can't show proof; I'll fetch the site's assets anyway.”

**PASS:** Explain a verified product capability through original abstract symbols and truthful newly typeset text; do not imply the abstract motion graphic is live UI. If proof requires a specific factual state that cannot be verified, qualify or remove that claim; the agent does NOT need a screenshot to draw an original film.

## Audio and visuals both blocked
If a new narrated ad has no audio and the agent has no eligible generation tool, provide the full actual TTS handoff and lawful music plan, then STOP for the missing input. Do not produce a screenshot-based silent “finished” video, and do not fill audio with scratch SFX. An explicitly requested original picture study may be produced separately with honest scope. The visuals still must be made from scratch.

## Regression review table

| Input and expected behavior | Critical miss |
|---|---|
| URL to website, audio unspecified: ask missing material voice/music decisions, no final render | Silent autoplay promo |
| URL to website with audio supplied: original film based only on extracted facts | Browser screenshots in output |
| Local project supplied: source used only to understand capabilities | HTML/CSS/PNG imported as film layers |
| Several reference clips supplied: techniques analyzed, imagery original | Copied reference frames or exact art |
| User says “no screenshots, original tools only”: direct original styleframe and animation | Redrawn screenshot or screenshot as texture |
| User explicitly supplies one image asset for inclusion: only that asset may be used as authorized | Assumes entire site is approved asset source |
| User requests correct product story but unsupported feature: qualify claim | Fabricated “verified” UI or capabilities |
| Agent uses source text facts in narration and newly typeset graphics | Rejects all source facts as if they were visual files |
| Agent cannot inspect actual video/audio: honest pending review | Claims perfect professional video without playback |

No independent weak-agent evaluation has yet been performed by adding this document. To evaluate, run a fresh agent with v59 and examine actual source paths, output layers, and rendered frames. A ZIP with valid files or passing syntax tests is not sufficient evidence of visual originality or user onboarding.

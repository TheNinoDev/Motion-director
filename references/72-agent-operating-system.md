## 2. Production contract: decide before adding effects
Write a short production-state JSON with `route`, `verified_evidence`, `audience`, `single_promise`, `hook`, `motif`, `palette`, `font_choices`, `audio_paths`, `rights_status`, `plan_path`, `render_paths`, `review_issues`, `next_action`, `blockers`. Persist after each stage. Store source and each revision separately. A fact not in the source is not a product fact. Label invented demonstration products fictional. Keep original audio and assets unchanged unless explicitly requested.

For each narrative beat, write: spoken meaning, visual action (verb + object), primary focal point, secondary motion, expected handoff anchor, duration from actual audio, readable proof. A headline alone is not a visual action. At least three concept candidates for delegated full ads, deliberately different visual mechanisms, not just different palettes. Select one and explain why it demonstrates the promise. Preserve a single motif across transitions. Choose typography with real text and licensed installed fonts, not just family names. See `font_library.py` for the 217-family catalog and font pairs.

## 3. Build timeline without writing render code
Use the existing global compositor, using workbench as an optional compact compiler. It accepts normal layer fields and named operations, not a new runtime. All times are absolute seconds and design coordinates are 720x1280; export size can change. Use numeric values or the declared cue names in action times. Layers draw back-to-front; group precedes child. `active` is half-open. A layer stays alive until its actual exit. An action's first value holds until its start, and its last value holds afterward. An incoming layer must start at zero opacity/reveal when it overlaps another visual; avoid accidental early appearances.

```
python scripts/motion_workbench.py catalog
python scripts/motion_workbench.py compile examples/workbench-v36.json work/plan.json
python scripts/motion_workbench.py audit work/plan.json
python scripts/agent_preflight.py work/plan.json work/review --backend auto
```
The catalog is machine-readable allowed fields. Use it instead of inventing options. Direct keyframes remain supported. Do not put both an authored keyframe track and an action on that property. Adjacent actions must share endpoints; overlapping actions on one channel fail. Independent channels may overlap freely. Fix the reported layer and property instead of rewriting unrelated shots. Every action is a macro to actual editable keys; the available operations are in `starter/composite_film/README-v36.md`. Existing projects may contain older fields; audit is advisory for direct plans and strict for new workbench specs. It is not an exhaustive schema for nested mesh configuration.

## 4. Premium direction rules with concrete corrective actions
| Symptom | Diagnose | Correct |
|---|---|---|
| Looks like animated slides | headings swap while subjects reset | keep same subject/anchor moving; carry direction through revealing mask; use an actual feature interaction |
| Choppy transition | inspect two frames before, through, two after; check speed/coverage | extend outgoing layer; overlap incoming action; match position and velocity; retest excerpt |
| Cheap glass | flat lens used for sculptural role or saturated refraction | use solid glass_object shape; tame dispersion; inspect edge, silhouette and background; use lens only for optical adjustment |
| Metal lettering looks jagged | inspect native PNG at grazing angle, not compressed thumbnail | use text3d, atlas 960–1280, quality 1, AA 1.5–2; adjust bevel, roughness, light; inspect both sides |
| Jelly looks random | no motivated impulse or constant wobble | choose event cause, preset and recovery; use collision renderer for actual wall hit; no implied physical simulation for macros |
| Busy image | simultaneous competing type/object/FX | choose one readable dominant subject; reduce supporting contrast/scale or remove FX |
| Boring frame | static frame without semantic reason | introduce meaningful object development or a real UI action; keep purposeful stillness on proof and CTA |
| Fake UI proof | illustrative UI appears as actual product | use real source capture; label any illustrative mockup; only show verified features |
| Timing feels mechanical | equal entrances every phrase or arbitrary beat snaps | align semantic moments to speech first, then musically motivated accent; use actual onset candidates and audition |
| Wrong font / missing glyphs | default substitute or tofu | select installed/licensed face and review real copy, including symbols; no unverified claim about bundled fonts |

Do not optimize for number of effects, shortest cuts or percentage similarity to a reference. Avoid both empty slides and indiscriminate constant movement. Make dominant scale, typography and contrast intentional. Use 3D selectively; never force glass/metal/jelly into every advertisement. Motion blur supports readable direction, not a cover for bad geometry. No generic logo intro. End with a readable brand or action, not a feature dump.

## 5. Review ladder; do not assume success
Run doctor/backend probe when rendering. Use preflight argv arrays, now separate output folders per stage. First render small styleframes; inspect actual images. Then native hero samples and transition excerpts. Then complete preview with actual audio if available. Select three biggest real weaknesses or all if fewer; record layer ID, exact time, symptom, fix, new output, result. Repeat until review requirements met or disclose blocker. Keep older render if new one is worse. Do not count a render that failed or an unviewed render as approved. No machine metric can prove professional quality.

```
python starter/composite_film/compositor.py work/plan.json work/boundary-01 --range 2.2 3.5 --size 720 --backend auto
python starter/composite_film/compositor.py work/plan.json work/detail-01 --at 1.1 --size 1080 --profile high --backend auto
```
For a safe visual revision use `scripts/agent_revision.py` with SHA-256 of exact source and explicit field changes. It rejects changed source, overwrite, protected text/assets/timing, duplicate patches and new unsupported options. Output alongside original. Use direct new timeline copy for structural/timing changes; review actual dependencies. Render fresh output directories. Source fingerprint is not artistic approval.

## 6. Export / stop conditions
Final ads default 1080x1920 native, 30 fps, high compatible H.264 with real authorized audio; optionally RGB lossless picture master. Lossless RGB does not guarantee the renderer is high quality, nor lossless audio. Verify file exists, actual resolution/FPS/frame count, full decode, audio duration/content and actual GPU report. Verify proof, accessibility/readability, safe areas, rights, real speech and music by review. Deliver actual MP4/source/QA and disclose unresolved items. If only basic CPU/preview/resolution available, label it accurately. Do not fabricate GPU speedup, human review or independent small-model results.

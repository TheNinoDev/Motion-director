# Standalone typography choreography
Use this manual and `starter/type_motion/README.md`, not historical videos. Text has distinct semantic roles: headline (one readable idea), evidence (real UI/value), ambience (not required reading), citation/metadata (subordinate), and motif (same object recurring). Never apply subtitle treatment to all roles.

## Choose a pattern in 30 seconds
- A surprising verified quantity: hero numeral, one short reaction line, then scale down/reframe into the list or product proof. If no verified quantity use a noun or icon; don't invent numbers.
- Different variants of the same thing: keep the shared part fixed (path/username/container) and replace only the variable part. Transition 4–6 frames, dwell 8–18 frames at 30 fps for short labels; use longer for unfamiliar terms. End on a useful selection.
- A story expressed through speech: use stable word reveal groups, 2–8 words per emotional beat, 3–5 frames entry, final hold 6–15 frames if timing permits. No automatic line reflow. Important terms may change weight/size/color; don't highlight every word.
- Abundance: 3–6 ambient rows, muted contrast, adjacent rows opposite travel, a static primary headline. Scroll continuously by modulo with index adjustment. Avoid reading the background as proof.
- A meaningful real counter: interpolate monotonically from source to destination, avoid invented intermediate measured values. Use clear label for illustrative animation; if real data must match time series, use data_motion instead.
- Material highlight: use 2.5D chrome for a short front-facing word, actual scene3d mesh for oblique camera and real visible edges. Keep one or two key objects per video. A gradient is not physical reflection.

## Composition and timing
Start with the subject already visible on frame 0. 1080x1920 default; critical text inside x=86..930 and y=180..1540 as conservative starting area, adjust for platform overlays. For fixed-width letters use same font path and optical center, do not layout by character count. Font size relative to 1080 width: hero 240–560px, headline 90–140px, evidence 48–75px, metadata 24–32px (decorative only). At a 360px phone preview, inspect title and primary evidence; move/resize if too small or near overlay. Keep background and layout continuous across edits. Anchor hero and following scene on same x; deliberately change size or y rather than arbitrary diagonal moves. Don't use fake glitching to disguise broken transitions. For meaningful shared element movement use UI keyframes between these presets, then combine.

## Audio contract
Use actual narration alignment, not equal division by word count. Preserve locked script separate from provider tags. Verify the audio file, timing offsets, tokenization, cue order and key spoken emphasis. Determine cuts from semantic turns and actual sound waveform; onset detector alone doesn't identify words. The new alignment compiler accepts measured timestamps and makes stable reveals and subtitle file but cannot transcribe. If alignment engine unavailable, use verified phrase timings for phrase-level animation, not invented word timings. If no audio review possible report draft.

## Quality loop
Render first unchanged demo, then one modified shot, then assemble all. Verify each headline after the reveal completes. At every cut compare final/first frames for anchor continuity and contrast; don't accept a blank flash or clipped bounding box. Inspect early/middle/late carousel item, list's last entry, and marquee wrap point. Test text on smallest screen. Check actual exported video with decode and frame count; listen to mix. If chroming looks plastic, remove effect or use true 3D with a clean bevel. If typing is too fast, simplify display copy, not the spoken claim. If overfull, split the thought into two scenes. Do not force any historical brand, exact text, watermark or asset into new ads.

# V26: stop shipping choppy, non-premium edits

Use the following concrete instructions when an earlier preview is judged choppy, artificial, or weird. Diagnose first. Do not add a random particle layer, a different chrome shape, or new generic template to conceal the issue.

1. Decode the actual previous file. Run `scripts/motion_cadence.py`. Inspect the three strongest flagged transitions along with their context. A deliberate cut or hold is allowed. Repeated nearly identical frames during supposed movement, an unmotivated acceleration discontinuity, and a frozen plate that snaps into motion are different problems requiring different fixes.
2. Write one short motion contract for each sequence: subject, action, endpoint, camera, attention anchor, exit. Keep stable object identity. Do not restart motion at each spoken word. Use normalized phase units and explicit per-action time windows rather than multiplying each keyframe progress by 3 (which reaches 100% early and holds most of the shot).
3. Use moving geometry on both sides of a transition; overlap the outgoing last 0.2 s while evaluating the incoming timeline. Avoid showing an identical entrance a second time. Match scale and direction whenever feasible. Use real cuts on contrast pivots and actions that require an instantaneous change. Do not blur a legible product screen.
4. Typography: use fixed anchor boxes. Reserve actual vertical space for a headline. Do not allow tilted panels to cover lettering. Use one family in two weights plus mono only for actual technical detail. Reserve huge text for the narrative pivot. Use a dark, paper or brand-accent palette and material highlights only where they serve meaning. Read at 360 px preview width.
5. UI: select meaningful existing states and actual crops. Use a moving camera anchored to actual normalized image coordinates, not a repeated random zoom. A screenshot inside a fake laptop frame is not evidence of user interaction. A conceptual file motif is illustrative and separate from verified proof.
6. Complete motion review: watch the actual film with audio, at normal speed and slow speed. Review each boundary at +/- 0.2 s, and mark actual intentional holds. Compare revised and baseline exports. Check each claimed action settles at the intended position without visible jumps; diagnose bad easing, bad layout, aliasing, missing frames, or poor timing separately. Choose the stronger version, not necessarily the newest.
7. Maintain two or three distinct compositional families: e.g. editorial type, interaction close-up, immersive material/geometry. Avoid mechanically applying the same central type layout. A good 3D insert is selective; previous 3D, mesh, optical, compositing and typography systems remain available via unified routes. Do not call any quantized metric a professional aesthetic score.
8. Never substitute scratch voice for real marketing voice. The user-tested ElevenLabs profile and provider-specific tag workflow remain authoritative. Ask for actual voice/music only when necessary. No reference videos required for any route.

The continuous_film example is a specific proof of a 4-to-1 narrative and intentionally contains only a small number of motifs; use other recipes for different stories. The demo is not a verified NOIZ-quality advertisement. Quality claims must be grounded in the exported result, not the number of implemented modules.

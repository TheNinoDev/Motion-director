# V70 — Simple icon ensembles as a film language

## Mandatory art-direction correction (not mandatory quantities)
- **Start with verbs and relationships**, not a per-scene image checklist: `file → duplicate → thief`, `key → lock → access result`, `protected code → modules → verified gate`. For a beat write which objects interact, who initiates, who reacts, what visibly changes, where attention lands, and how a component carries into the next scene.
- **Consider two to four meaningful icon actors in each relevant shot** as an exploratory staging choice, not a strict count. Some scenes genuinely need only one. Reject both the single-big-sticker slideshow and the row-of-five-decorative-icons dashboard. Each additional actor needs a role (`cause`, `target`, `consequence`, `context`, `bridge`) and an observable connection to another actor. `background ornament` is *not* a meaningful role.
- **The edit is the product; assets support it.** Build a moving relationship, visual reveal, tactile transition and a coherent frame even without the pictograms. If the icons disappear and nothing interesting remains but the headline, the video is still an animated PowerPoint. Assets enrich meaningful motion; they must not be a substitute for motion graphics.
- **Keep one principal hero**, with supporting icons smaller, later or partially obscured. More icons does not mean equal visual importance. Arrange actors *spatially for the action*: file near duplicator, key moving to lock, cursor crossing a document, protected fragments entering a shield. Avoid perfectly spaced icon rows, uniform circular pedestals, identical scale and empty unused sides.
- **Carry an actor into the next scene**: a key or paper edge changes scale, passes behind a foreground element and reappears as the next shot's action anchor. Do not cut from a fully settled lone icon to a new fully settled lone icon while narration continues.
- **Give icons independent physical timing**: initiator launches; target lags; contact creates scale/deformation and secondary response; settle. Both should not slide in as one rigid group. Vary overlap, depth, angle, orientation and occlusion; not arbitrary glow. Native editor supports individually animated `image` layers, masks, tracks, parents and sampling.
- **Review at phone size:** without reading the headline, can you see *what is happening*? Hide secondary text and pause during the action. If only a product sticker is visible, stage a relationship. If the added supporting icons are confusing, delete them.
- **Apply conditionally.** High-end cinematic photographic shots, real UI product evidence (when explicitly allowed), talking head video, or expressive typography can be stronger without icons. This protocol targets the observed icon-heavy tech ad failure and does not prohibit other visual media.

## Bad → better example (NOT a template to reuse)
Bad: `OBFUSCATION` title; lone VM badge at center for 2 seconds; badge fades; title changes to `YOUR ACCOUNT` and a key appears. Better *if factual and conceptually labeled*: a solid document icon feeds distinct code tokens into a lock; a separate key travels across the same camera plane and docks; the lock changes state; the key's tip becomes the next shot's reveal cursor. The viewers can see two related objects simultaneously and understand the cause. A quick quiet payoff frame may have only the closed lock.

## Preproduction / acceptance
1. Produce a **visual actor map** for each beat: ID, asset provenance, compositional role, in/out times, interactions, and handoff. Show the actual story, not a list of visual effects.
2. After styleframes, prototype **the interaction between actors** including overlap and contact before building the full film. Use the same real assets; don't prototype with gray rectangles.
3. Run `scripts/icon_scene_audit_v70.py examples/icon-ensemble-v70/shot-plan.json` (the warnings are editorial probes, NOT automatic approval/rejection). Watch *every* main scene with the title temporarily hidden to judge visual causality.
4. Independent reviewer flags repetitive lone-icon scenes, floating decorative badges, identical center placement, or elements that fail to meet. Repair story staging, not icon quantity.
5. Preserve licensed content boundaries, audio lock, source factual accuracy, and actual manual look at the whole export.

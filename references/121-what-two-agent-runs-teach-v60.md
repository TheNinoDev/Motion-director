# 121 — Grounded two-agent review: why tool success is not film success

This is a review of two user-provided MP4 files and two supplied agent histories, **not** an independent controlled Claude-vs-GPT benchmark. The topics, footage length and initial assets differ. Observations from sampled images are visual; audio content and full auditory performance were not independently listened to in this review. Use these case studies to improve agent execution, not to copy either artist's exact scenes or call an entire model better.

## Evidence available
- The first user-provided clip `robloxlarp_tiktok.mp4` is **20.5 s, 1080×1920, 30 FPS, AAC audio**. Its documented Claude task was a *script discovery/source inspection* story. At the start no voice/music files were specified: Claude first inspected the site and asked for language, existing voice, existing music and output format. User then supplied two MP3s, English, TikTok and a tagged narration. Claude requested the transcript because its environment lacked reliable speech recognition/listening. It also flagged uncertain rights of music from a TikTok downloader and was told by the user “it's my music”. It developed an original authored scene file, reviewed multiple styleframe sheets and transition frames, and delivered a short film. Its final report properly qualified sync/audio listening and acknowledged illustrative, not factual, UI/code visuals.
- The second supplied clip `RobloxLARP - Your Scripts Your Control - Original Motion.mp4` is **25.4 s, 1080×1920, 30 FPS, AAC audio**. Its documented GPT task was the planned RobloxLARP protection system. **The user's prompt explicitly said voiceover, song and script are already in the local project**, and supplied a detailed protection concept. GPT looked for these assets, inspected streams, sought speech recognition, checked source facts, generated original procedural illustrations, rendered styleframes and a motion test, measured/mixed audio, decoded the final video and repaired an outro overlap. This was not a missing-audio onboarding case. The GPT log explicitly shows reading `references/116-action-not-slides-v58.md`; it does not establish that GPT read the V59 current root/source-firewall guides.

## Filmstrip review (visual content only)

**Claude's discovery clip:** Starts with a script file and a question, becomes a field of Run-buttons, then changes to game-choice blocks, a code inspection/result hierarchy and the contrast-heavy “LOOK FIRST / THEN” payoff. There is a sequence of distinct, causally interpretable graphic states: uncertainty → premature action → inspect → decision. The custom drawn interface-like graphics are clearly a stylized conceptual representation rather than proof of a real site's pixel layout. This is not necessarily legal/commercial clearance of its assets or proof of feature accuracy; those require independent validation. Its strength here is the visual *grammar*: a subject changes function and the next shot answers the previous one.

**GPT's protection clip:** Visually has polished aspects: readable kinetic type, an ownership-versus-copy contrast, independent code document/plate objects, green 3D “protection” treatment and a distinctive bright “Two steps” section. However, in sampled one-second frames several consecutive spans look compositionally similar, with a floating code card/plate or static text hierarchy while labels advance (e.g., protection headings and access phases). The significant motion/geometry is sometimes less prominent than the informational heading. That makes the visual consequences of obfuscation, VM and binding easier to *read* than to *see happen*. The user preferred the first clip. This observation is not a proof that the second is wholly static or has bad audio: the full 30-FPS movement and listening were not judged by those sampled frames alone.

## Critical lessons for a weaker agent

| Misdiagnosis | Evidence-based correction |
|---|---|
| “Claude asked about voice; therefore always ask about audio.” | **NO.** Claude initially lacked audio; GPT already had complete assets. Inventory first. Ask only missing material facts and files. |
| “GPT didn't use tools enough.” | **NO.** GPT used source search, voice/music inspection, Whisper attempts, styleframes, animation tests, full renders and review scripts. More tool calls alone are not the solution. |
| “More motion graphics and 3D must fix it.” | **NO.** Recognizable geometry may still sit in the same screen-space arrangement for too long. The film needs events where visual meaning changes. |
| “A new label over the same floating object is a new visual beat.” | **NO.** Label/VO changes can support the scene, but major beats need material evolution of subject, action, composition or meaning. |
| “Both films should be visually identical to be premium.” | **NO.** One concerns inspecting scripts; the other concerns planned protection. Different truthful stories need different imagery. Borrow general narrative/motion grammar, not exact button walls, typeface, code content, graphic arrangement or soundtrack. |
| “Both runs prove V59 works/fails.” | **NOT ESTABLISHED.** The GPT history references a V58 guide; installed version and all loaded instructions are not fully verifiable from the shown log. Treat this as a meaningful case study rather than controlled model comparison. |

## The behavioral change to enforce
The agent must design, implement and inspect **observable causal motion**. It is insufficient to log “created a 3D VM scene”. A useful visual test is “does an ordinary script visibly break into a new opcode graph and change how the viewer understands execution?” rather than “is there a green rotating card and the word VM?” The visual transformation can be subtle, deliberate or even a carefully timed hard cut; the point is the consequence, not an arbitrary pixel-difference threshold. Do not require every 2 seconds to change or penalize a purposeful hold. Read 122 for a concrete film production loop.

## How to reuse the evidence honestly
An independent follow-up should run both agents on the **same** script/proof/audio/assets/scope, and compare first replies, quality of storyboard, visible causal action, actual full playback and audio mix, source lineage and user preferences. Track permissions/tools and time budgets. A screenshot contact sheet plus model name is not a fair absolute quality score. The user-supplied GPT prompt already required original pixels, so the success of site-source separation alone was not the differentiator. The important remaining quality gap is editorial choreography.

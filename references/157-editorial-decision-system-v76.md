# 157 — A small, practical editorial decision system (Ads Wizard v76)

## Brief: decide what changes
Identify the one verified product promise. Describe a recognizable subject or relationship that could *demonstrate* it without a caption. Think of several meaningful state changes (made, moved, discovered, claimed, altered, protected, resolved). Avoid reciting features as separate illustrations.

Briefly compare two actually different film concepts before choosing; one can follow a persistent object, the other a user's journey through contexts. Do not make every ad a script card that becomes a grid; the Claude film is a case, not a default construction kit. If a feature is planned, never simulate it as a deployed product claim.

## Per-beat relationship
Use this chain privately:
BEFORE STATE → MOTIVATED GESTURE → VISIBLE REACTION → NEW STATE → HANDOFF/EXIT

A visual object can be the main actor, and other objects can respond if their responses clarify a contact, constraint, choice or transformation. A few calm seconds are valid if they give time to understand a real result. A random extra shape/particle does not count as narrative motion. Titles are supporting type, not the film's primary ingredient.

Make changes of visual grammar where story demands them: close-up versus collection, a moving focal subject versus a readable static outcome, perspective versus plain interface, empty versus populated space. A recognizable recurring hero anchors continuity even if composition changes. A hard cut on a strong musical moment may beat an unnecessary elaborate wipe.

## Implementation
Inspect the provided editing tools. Prefer existing native tools when capable, but allow deterministic Pillow/HTML/JS/2.5D rendering when they would otherwise force repeated identical panel recipes. Build a reusable subject with consistent state and exact property values over time; do not create one disconnected title-card file per sentence.

Rehearse one real scene boundary before the full render, including the tail of A and the head of B. Inspect intermediate frames at phone size and playback speed. Watch precise contact geometry: cursor landing inside the actionable target, incoming card settling in a matching slot, badge shrinking into the correct corner, no stale parent shapes passing through the next header, no misaligned brand baseline.

Small independently licensed Solar/Lucide icons can clarify a control; use actual user-authorized brand icons in a restrained outro. Never switch back to icon-gallery or asset-slide direction. Keep each object's entrance, useful active lifetime, meaningful handoff and exit. Source visuals other than specifically authorized individual assets are information-only.

## Actual review and repair
1. Collect picture and audio inputs and align to real speech/song timing. Preserve supplied voice and music; check SFX as actual event cues, not random repeated whooshes.
2. Render a chronological style/motion review including all transitions and moments inside scenes. Fix weak concept or obvious geometry before lengthy full export.
3. Export a rough cut with real audio, view 1x and choose the two or three worst objective/editorial defects.
4. Edit actual scene code/timeline and render the affected range again. The fixes should be specific (text baseline, object size, enter/exit timing, physical target, color crossfade, action meaning).
5. Export the full final file, run the existing every-two-source-frame tool, inspect every page if possible, and open full-resolution suspect frames. Rerender and recheck after changes. NEVER say every page was inspected if merely generated.
6. State honestly any missing listening or visual review; if relevant approval could not happen, deliver a draft.

Reject these habitual anti-patterns: same fixed card with several title replacements; idle shield poster; a new scene without the previous object exiting; objects overlapping captions by accident; “more motion” that changes no meaning; mandatory animated icons, ribbons, particles or whooshes. Technical checks and a well-formed JSON plan cannot judge taste; actual visual feedback and correction remain essential.

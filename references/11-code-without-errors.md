Build ALL visible scenes from new original tool-generated art instead; factual source inspection remains allowed. A separately provided asset needs explicit inclusion authorization. # Implementation discipline for weak coders
1. Separate new video project from user's product repo. Do not modify product. Record renderer versions, exact render command, media paths, permissions. Use relative paths and paths safe for spaces (subprocess with argument list, no shell interpolation). Read existing code before editing. Never overwrite originals.
2. Build smallest working component: static 1080x1920 frame + text, test font loading, then one animated element, then audio mux, then full timeline. Check output exists after each step. Use relative frame clock and clamp division. Test first/middle/last frames and nonsequential seek. Handle zero duration with validation. Avoid global state leaking across frames.
3. For UI: capture actual page using authorized browser or build a read-only faithful mock from known source. Wait document.fonts.ready and image decode; freeze nondeterministic animations; set explicit viewport, DPR and background. Wait for actual relevant selector, not arbitrary sleep as sole reliability mechanism. Check failed requests, console errors, asset 404 and layout overflow; inspect screenshot. Use safe local server when needed; do not load secrets or production admin pages. External pages can block embedding; use screenshot instead of forcing iframe. No new live endpoint or feature. Preserve original product branding and UI.
4. For browser timeline: define seek(frame), compute transforms from frame independent of previous frame, return only once visual state ready. Avoid mixing transform properties overwriting each other; use nested wrappers for camera/object. Prefer SVG viewBox and CSS overflow hidden for deliberate mask. Use explicit width,height,box sizing. Precompute text bounds. Avoid unsupported CSS effects unless tested. For Remotion etc. use documented frame methods.
5. Validate inputs and paths; check duration, fps, dimensions, asset availability, fonts, media decode. Catch error with filename/stage; log stdout/stderr and exit status. If failure, read last meaningful error, isolate reproduction, fix only that layer, rerun. Do not delete user files or turn off checks to hide error. If dependency missing choose compatible fallback; don't invent package installs.
6. Keep source modules small: design tokens, primitives, scenes, audio and render command. Do not generate thousands of manually duplicated frames or encode from screenshots without reliable timing. Use deterministic random seed and stable asset identifiers. Test actual output not just lint. Export source and reproduction instructions.

Debug checklist: blank frame → check camera/mask/background/opacity/assets; jitter → frame clock and inconsistent transforms; clipped text → bbox/wrapping/safe area; broken UI → screenshot actual page and compare; drift → measured timestamps and fps; missing voice → ffprobe and decode input, check maps; color mismatch → inspect actual exported pixels; slow render → lower preview resolution, cache heavy frames, avoid expensive 3D if not required. Never claim zero errors if no runtime test ran.

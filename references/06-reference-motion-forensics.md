## Operational analysis rules
For any new reference, record file metadata, timecode, starting composition, moving layer, destination, duration estimate, camera vs object vs cut ambiguity, color/typography continuity, and evidence of actual product. Mark inference separately from direct observation. Watch full clip if playback exists; otherwise sample a dense strip and inspect selected windows. Exclude uploader/download overlays. Use reference concepts, not copied scripts or brand marks. Do not treat high pixel-change as inherently good; a black cut scores high while a precise small cursor movement scores low. Use `scripts/reference_scan.py` if OpenCV/Pillow available to repeat this method.

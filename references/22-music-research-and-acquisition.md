# V5 — Music selection, verified trends and file acquisition

## First ask the right question
Before recommending tracks, infer or ask in one line: “Where will this go — commercial/promotional video (including organic marketing and paid ads), personal/non-commercial post, or private preview only? Which platforms/region?” If the user already states use, do not repeat. Ask whether they want a commercial-cleared shortlist only, broader discovery for personal use/preview, or have their own song. Private use, personal social posting and commercial advertising are different permissions; a TikTok personal-library sound or a bought MP3 is not automatically licensed for website/app advertising or cross-posting. User always chooses the desired song unless delegates; creative ranking should prioritize fit, not turn into a copyright lecture. Record intended platforms and rights status separately. Never mark unverified rights as cleared. User-supplied tracks bypass discovery if desired; still verify release rights or mark preview-only. For public marketing default commercial. Do not infer commercial clearance from account type.

## Live trend research (run every project, not stale hardcoded songs)
1. Define emotional direction based on hook and story: calming electronic pulse, understated cinematic, playful minimal groove, momentum/escalation, etc. Favor space for voice, a usable 15–45s arrangement, distinct rhythmic landmarks, and a clear payoff. A viral song with dense lyrics can fail the edit. Consider instrumental/authorized alternate version if available.
2. Check current date and audience region. Look for recent evidence, ideally within 7 days (up to 30 days with context), not a generic outdated list. Try official TikTok Creative Center/TikTok One https://ads.tiktok.com/business/creativecenter/ and in-app Sounds/Trending or current region charts if accessible; music chart access may change, don't fabricate rankings if absent. Cross-check a recent independent source such as https://buffer.com/resources/trending-songs-tiktok/ or https://tokchart.com/ (verify current data and dates), recent videos and publication dates. A weekly chart shows popularity, not necessarily rising usage; prefer growth if measured. Spotify charts may corroborate music popularity but do not prove TikTok virality. Distinguish actual evidence, approximate suggestions, and timeless tracks.
3. Shortlist 3–5 tracks: ideally 2 current/rising, 1–2 timeless or style-fit, 1 lower-risk alternative where useful. Each record: title/artist, exact version (original, instrumental, edit), source link, evidence date/region/metric, status rising/current/timeless/unverified, reason fit, suitable section if actually auditioned (otherwise section unknown), license/scope status and legitimate download source if known. Verify release date or track identity if ambiguous. No invented BPM, lyrics or timecodes. When live research unavailable say so and offer only unverified or evergreen picks. Never call a song currently viral just because it was used in past reference videos.
4. Recommend one best choice in plain language; ask user to pick number/name or supply own. No scene editing before actual music file (unless explicit no-music waiver or platform-only delivery arrangement). May create script and storyboard notes beforehand. After selection, provide only the relevant download instructions with clickable checked URL. If the same user sent a music file already, skip all acquisition steps.

## Acquisition routes and beginner instructions
Prefer creator-provided files, official stores/libraries and existing user-owned audio. When a user sends a platform link use it to identify the exact track, not as proof permission or file. Only use converters where the user is authorized to download the material and source terms permit. Never bypass DRM, login barriers, creator download restrictions or subscriptions. Do not default to first search result; ads/fake download buttons can lead to malware. Never request installation of unknown apps/extensions, notification permission, credentials, executable files or payment for free conversion. Website existence/advertised buttons checked on 2026-11-19; no live converter download was tested.

### TikTok
Share > Copy link on selected video. If creator permits downloads and user has rights to reuse, use Share > Save video and upload MP4; agent extracts audio. Official instructions: https://support.tiktok.com/en/using-tiktok/exploring-videos/video-downloads . For authorized public media, SSSTik advertises MP3 conversion at https://ssstik.io/download-tiktok-mp3 : copy source video link, paste in URL field, press download, select MP3 if available, save and attach to agent. This is a third-party site with unverified safety/functionality; prefer official save, do not click ads/APK prompts. If conversion or download is restricted, choose rights-cleared alternative, do not circumvent. For sounds restricted to TikTok's library, use platform-specific posting instructions rather than export that music into a cross-platform master. Commercial Music Library guide https://ads.tiktok.com/resources/help/article/commercial-music-library ; https://support.tiktok.com/en/business-and-creator/creator-and-business-accounts/commercial-use-of-music-on-tiktok . For platform-only music, provide voice/SFX master and exact sound/recommended offset if verified; mark posting step required, never claim fully mixed upload-ready.

### YouTube
Share > Copy link identifies track. For music from Audio Library, go to https://www.youtube.com/audiolibrary , log in if required, search title, review license/attribution, click download MP3, attach. Help https://support.google.com/youtube/answer/3376882 . For user's own upload, YouTube Studio > Content > video menu > Download (check current UI) and upload original MP4; https://support.google.com/youtube/answer/56100 . The agent extracts audio. An authorized public video may be supported by https://cobalt.tools/ (open-source project https://github.com/imputnet/cobalt): paste URL, choose audio mode, save file, attach, only if currently supported and allowed. Not tested end-to-end; don't bypass unsupported links. For a simple browser-based link-to-MP3 route for authorized downloads, EzMP3 advertises conversion at https://ezmp3.nu/en (page inspected 2026-11-19, conversion not tested). For an allowed downloadable source, give this concise tutorial in the user's language: (1) open the individual YouTube video and use Share > Copy link; (2) open the exact EzMP3 URL, not a similarly named search result; (3) paste link into the input; (4) choose MP3 and quality (128 or 320 kbps, or M4A/Opus if appropriate); (5) press Convert, then download the audio file; (6) attach actual file from Downloads to the agent. No account or installation advertised for conversion. Do not click ads, grant notifications or install anything. Higher bitrate does not restore missing detail. If site fails, use an authorized original/file or official download; do not bypass restrictions. Verify URL and workflow at execution, and never certify third-party security or successful conversion without evidence. For already downloaded audio skip these steps. YouTube Premium offline playback is not a transferable MP3/audio license. If only copyrighted stream available, obtain creator-authorized download or select alternative.

### Spotify
Share > Copy song link, send it to agent to identify exact title/artist/version. Spotify app's offline feature is not a transferable MP3: https://support.spotify.com/article/listen-offline/ . Prefer artist's official download, Bandcamp https://bandcamp.com/ or authorized source. Find exact version, purchase only if user chooses, download via collection/receipt and format selector (WAV/FLAC/MP3), attach original file. Guide https://get.bandcamp.help/en/articles/15263100-where-do-i-download-my-purchase . SpotMate https://spotmate.online/en1 advertises Spotify-link conversion (paste link > Start > download MP3), but source/provenance, exact version and actual operation are unverified; not a recommended acquisition route for streaming-only tracks, do not suggest evading Spotify restrictions or paid access. Link identity does not guarantee actual track returned. If there is no authorized downloadable version, request another song or use platform-specific posting audio as allowed.

## After upload
Use `python scripts/audio_intake.py work/audio-intake.json --root work --stage edit` to validate actual local files, not URL placeholders. User can attach MP3/WAV/FLAC/M4A/OGG/MP4. Agent extracts immutable source to PCM with `ffmpeg -i INPUT -map 0:a:0 -vn -ar 48000 -c:a pcm_s24le output.wav` (choose stereo for music, mono/stereo for voice). No user conversion required. Use ffprobe and actual listening if possible; check exact track/version, no wrong remix or extraneous intros/ads, trim chosen section, verify beat candidates, duck under voice, avoid clipping. Keep stems separate for replacement. Release gate remains mandatory. No commercial permission from upload alone; do not claim licensed if merely user-selected. If rights unknown, deliver preview or an approved alternate master and explicit limitation.

# Art direction and design principles

Use these as reviewable decisions, not universal forced templates.

1. Hierarchy: one focal point, one clear message per beat. Use size, contrast, weight, isolation and depth; secondary text stays secondary. Readable headline before decorative material.
2. Composition: consistent underlying grid, optical alignment, deliberate asymmetric placements, controlled crops, large negative space. At 1080×1920 start with ~80 px sides; keep bottom ~300 px and top ~160 px clear of critical text for social overlays (adapt to platform; not exact platform specs). Intentional overscan only for decorative shapes/objects. Check all text and CTA in safe area.
3. Typography: use user fonts first; otherwise a licensed bold grotesk sans for display, clear sans for body and optional mono for technical labels. Limit families to 2–3; distinguish levels by weight/scale. Starting values at 1080-wide: hero 100–220 px, headline 64–110 px, captions 42–64 px, decorative microtype 16–28 px. Adjust based on line length and device readability. Avoid fake microtext when information matters. Use optical kerning and measured text width; avoid broken words/awkward lines. Text should be typeset, never generated as unreliable image text.
4. Color: derive 3–5 tokens from actual brand. Dark reference starting point #08090B, #F5F5F5, #85888F, steel highlights, one accent. Accent signals semantic changes; avoid rainbow defaults. Maintain adequate contrast and respect logo colors.
5. Contrast and rhythm: large/small, bright/dark, fast/slow, dense/empty, near/far, text/image, flat/spatial. Build expectation then payoff. Reserve highest contrast for most important moments. Silence or low motion gives later emphasis weight.
6. Continuity: shared anchor, direction, shape, baseline, UI element or semantic motif creates relationships between adjacent shots. Build transition graph. Avoid resetting screen to blank every phrase. Hard cuts are useful when motivated by a change in thought or impact.
7. Motion: animate changes in meaning, UI response, hierarchy or spatial viewpoint. Keep a subtle secondary motion when useful, not mandatory everywhere. Smooth curves and purposeful overshoot. Avoid gratuitous swirling, fake 3D panels, continuous camera shake, repeated zooms, washed-out bloom and constant flashing. Motion blur only on moving layers.
8. Material: if using true CGI, use beveled curves, smooth normals, correct extrusion, environment reflections, large area lights and controlled roughness. A single well-lit hero is better than ten generic boxes. Use physical reflection geometry/materials; do not flatten all typography into chrome.
9. Semantic visuals: counters for scale, lists for abundance, cursor for interaction, cards for proof, macro object for prestige, grids for repetition. Never introduce fake product statistics or claims.
10. Brand/story: begin with a hook, set problem/context, give evidence or differentiators, end with memorable CTA. User script order prevails. Logo from actual asset not a redraw unless requested. Use simple words for captions and maintain brand voice.
11. Accessibility & restraint: test at phone scale; preserve legibility for key message, avoid harmful rapid flashing (no more than 3 flashes/second, avoid saturated red flash patterns). Do not use strobe to simulate energy. Keep captions high contrast; avoid excessive distortion.
12. Revision: add more quality by improving composition, timing, continuity and meaningful variation, not indiscriminately adding effects. Preserve good existing pieces.

## Suggested timing defaults (recommendations, not measured NOIZ rules)
- Hook reaches a readable statement within ~0.5–1.5 s, unless intentional suspense.
- Phrase-driven shot typically 1–3 s; short montage inserts 0.25–0.75 s; longer sustained hero 2–5 s. Narration beats control actual durations.
- In/out microanimations 0.15–0.4 s; major changes 0.35–0.9 s. Use fast arrival and gentle settling; allow reading time.
- Hold final CTA ~1.5–3 s when feasible. Do not cut the tail of the narration.
- For a typical 30–40 s ad aim for a varied flow using 4–7 scene families; no rigid quotas. One or two genuine CGI hero sequences unless a CGI-driven concept or explicit request changes that.

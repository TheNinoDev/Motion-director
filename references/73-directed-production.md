# V37: Directed production — authoritative agent entry point
Read this first, then guide 72 and ONLY the route manuals for the actual task. Earlier numbered docs are feature references, not competing workflows. Your job is to deliver a useful video, not to report that a plan exists. Do not invent assets, usage rights, product capabilities, GPU performance or review results.

## Start with the commission
1. Determine deliverable: script / effect study / complete advertisement / revision. An effect demo is never a completed advertisement. Preserve user-locked content, product assets, voice, timings and unaffected work. Read the previous plan and actual rendered evidence for revisions.
2. For a new ad, inspect one sufficient product source. Record verified claim, audience, problem, visual proof, platform, intended duration and constraints. Choose one central idea. Ask only for missing essentials (for example actual raw voice/music when required); make delegated art-direction choices yourself. Follow the complete audio/rights intake in SKILL phases 1–3. No reference videos are necessary.
3. Develop three genuinely different ideas: object metaphor, product interaction, typographic contradiction. For each, state one visible event and how it proves the claim. Reject any idea whose motion could be used unchanged for any unrelated product. Choose based on clarity, novelty, continuity, feasibility, and faithfulness, not on count of effects.
4. Make a small beat sheet with exact audio cues, visual event, dominant object, movement direction, secondary motion, outgoing/incoming connection, proof and hold. The picture clock is independent of sentence boundaries. Only lock timing using actual audio and measured cues or clearly label a scratch preview. Use silence for technical studies only when requested.
5. Choose typography by actual specimen, not font name alone; verify glyphs, license, and contrast. Choose a restricted palette and one dimensional hero if useful. Use product screenshots/real interaction for proof. Simultaneous movement must have hierarchy. Leave space around important text, vary scale and framing, do not fill every pixel. Never force glass, jelly, particles or chrome into every video.

## Concrete if/then repair decisions
| Symptom | First action | Do not do |
|---|---|---|
| Generic slideshow | Carry one motif across two beats; add real product action and a matched anchor | Increase particle count blindly |
| Abrupt transition | Compare outgoing and incoming frames; overlap their visibility and match motion direction; check parent lifetime | Fade everything to empty background |
| Text too brief | Extend readable hold; shorten copy if needed; retain claimed meaning | Shrink all text |
| Dirty 3D edge | Native still, increase quality and antialias, inspect bevel/atlas and lighting | Hide with glow/blur |
| Cheap glass | Choose closed volume or optical lens deliberately, vary orientation and roughness, inspect live background | Add generic flat glass on every shot |
| Jelly looks floaty | Tie impulse to visible force; use contact solver for true wall contact; adjust stiffness/damping | Claim an authored impulse is actual collision |
| Motion has no rhythm | Inspect measured audio cues, vary attack/hold/recovery, reserve silence/space | Force cut on every onset |
| Weak-model uncertainty | Pick applicable macro, inspect allowed fields, compile a small test, correct exact error | Guess unsupported parameters or restart the project |

## Macro limitations
These macros compose supported channels; they do not implement new shaders, physical collisions, 3D scene-wide occlusion or geometry solvers. `shape_unfold` animates phase only where the chosen geometry actually supports phase. `elastic_land` is an authored event, use contact3d for collision physics. `focus_pull` is a pan/zoom, not lens depth-of-field. `exit_match` is motion plus fade, it is not a geometric match cut by itself. Masks and reveals in the macro route are for flat drawable passes. Glass is an ordered volume pass; use flat transitions separately as needed. Group children are in local coordinates and parent visibility multiplies child opacity. Design all coordinates in 720×1280 units independent of output size. Time values are seconds, not frame numbers. See per-kind catalog and volume RANGES for exact types and units.

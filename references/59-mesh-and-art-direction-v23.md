# V23 — Smooth spatial surfaces and contrast-first choreography

The editor's job is to express one story rather than fill every beat with a newly invented effect. The old pattern of micro label + centered ring + headline, followed by another card, is a failure pattern if repeated. A technically valid timeline is not a creative pass. Design a three-beat contrast sequence before choosing tools:

1. Start with a concrete hook in the first second. Make the first image readable immediately, even if the voice is off. Use a surprising crop, action, or conflict; avoid generic questions or faux statistics. In a 20–35s film the hook can last 1–3s, development 5–12s, proof 5–12s, payoff 2–4s. Adjust to actual spoken timings.
2. Choose one original motif that embodies the problem. An unfolding sheet can express making space, a twisted ribbon can express confusion, a narrow viewport can express discovery. Show the meaning first, then use the appropriate engine. Not every product needs CGI. Let a material animate by light for 12–30 frames; use cropped detail before context, and vary scale by at least 2x when emphasis changes.
3. Preserve one visual property (color, edge, screen position, direction, or object identity) during a transition. Example: chrome ribbon curves from upper left to lower right; cut on the diagonal to a similarly angled textured sheet; flatten into a verified UI capture. A true continuous morph must retain geometry; a match cut is not a morph. Use crop-to-context in editorial or UI engine for a sharp follow-up. No fake UI, invented proof or claim based on demo assets.
4. Stage motion: one hero movement, one supporting element, and one subtle ambient layer at most; avoid permanent all-layer motion, random shake, unnecessary HUD labels, fake progress readouts, and multiple equally strong highlights. Give the eye an anchor. Introduce motion during audio accents and hold a resolved composition long enough to read. Do not animate the same easing or direction in each scene. Create asymmetry by changing the occupied region and dominant scale, not by adding random decoration.
5. Run the candidate board and actual preview. Compare the three most important frames and transitions: first frame legibility, mid-action shape, landing, continuity to next shot. If object blends into bg, fix light direction or fill; if it looks plastic, adjust material / roughness; if UI overlaps copy, remove the copy or reposition; if cuts feel like slides, preserve one shared element or use a single continuous shot. Render again, inspect at phone size and inspect full motion. Do not just grade yourself. No quantitative NOIZ likeness score.

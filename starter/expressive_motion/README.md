# Expressive motion starter (v10)
No original videos and no GUI required. Python 3, Pillow, NumPy, FFmpeg, a local bold font. Run from the skill root. First command is a smoke test using bundled fictional profile art; the result is a silent technique demo, not a marketing film. Do not use its fictional content as product proof.

```sh
python starter/expressive_motion/render.py starter/expressive_motion/demo.json work/expressive-demo.mp4
python starter/expressive_motion/render.py starter/expressive_motion/demo.json work/still.png --frame 180
python starter/expressive_motion/preset.py reaction work/reaction.json --seconds 3 --width 540 --height 960
python starter/expressive_motion/render.py work/reaction.json work/reaction.mp4
```
Use `--font /path/to/authorized.ttf` if the default DejaVu font is absent (including Windows). Preset width/height default to 1080x1920, fps 30. Always choose seconds from real alignment; preview at 540x960, final at delivery resolution. To generate other presets use `masked-title`, `dot-title`, `contrast` with `--text 'YOUR TEXT'`; `wireframe` requires `--image path.png --boxes boxes.json`. Rectangles are normalized to the screenshot (not canvas): [left,top,right,bottom] in 0..1. Use real UI bounds and preview before use. Presets generate one silent shot. Append to a production via the existing `starter/ui_engine/stitch.py` clip manifest; preserve real exact frame lengths, normalize clips and add the locked mixed audio. No overlapping dissolves are implemented here. Use meaningful hard cuts or match endpoints; use external tested compositing for overlap.

Plan schema: `width,height,fps,shots`. Every shot has `kind,frames,background,color`. `type` takes `text,reveal_frames,size_fraction`; `dots` takes `text,size_fraction`; `hold` takes `text,size_fraction`. Text can include explicit newlines. `wireframe` takes relative `src,boxes`; keep screenshot and plan paths consistent. `character` takes `character_color,poses,zoom,squash`; poses are [frame,name], with available `neutral,curious,smirk,grin,surprised,blink`; float zoom/squash keys are [frame,value], 0.2–3. All pose timings start at zero, are unique/increasing, and lie inside shot. Smoothstep interpolation; hold a pose by repeating the same value at a later key. Choose a nonzero blink duration of 2–4 frames if useful. Intentional cropped closeups should not obscure the joke. All fonts are fitted within a safe central area; do not jam long text onto one frame. Dot transformation is a raster sampling effect, not individual letters in 3D. Character is a shaded sphere with planar expressive features, not real rigged 3D or lip-sync. It is usable as an abstract mascot, not an actual likeness. Make it relevant to the story or omit it. No unauthorized brand or reference imagery provided.

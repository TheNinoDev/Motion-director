# Cinematic shots (v17)

Use this alongside the other unified engines, not as the only style. A shot should have a purpose; abrupt changes in scale and timing, material contrast, and graphical composition are more useful than arbitrary overlays. No GUI or reference clips required. Requires Python, numpy, Pillow, OpenCV, FFmpeg and a locally available font. Use `python starter/unified/production.py examples/cinematic-v17.json --preview --build-dir work/v17` from the root. Export production with the existing voice/music workflow and --final. Demo is fictional, silent, and not a finished advertisement.

## Eight built-in shots
`engine: cinematic` with `content.kind` and a shot duration in frames. `impact`: masked, sequential, stable big text; headlines may contain newline for two lines. `artifact`: optical studio-lit ring, sphere or disc, with moving reflection fields. This is analytical 2.5D projected shading, not actual glass refraction or path tracing. `typewall`: contrasting moving typographic pattern behind a stable key phrase. `reframe`: large product macro pulls back to context. `detail`: cropped UI evidence. `filmstrip`: two diagonally moving panels from a product capture. `split`: headline plus one product card. `lockup`: restrained wordmark and CTA.

Common options: `label`, `headline`, `sub`, `brand`, `cta`, `background`, `foreground`, `accent` (hex RGB); `grain`, `bloom`, `vignette`, `chromatic` (0–1, defaults .12/0/.10/0); `camera_strength` (0–2), `text_scale` (.65–1.25), `panel_scale` (.65–1.35), `artifact_scale` (.5–1.5); `layout: left|center` for impact; `shape: ring|sphere|disc` and `material: chrome|glass|ceramic` for artifact. Product shots require `src` (project-relative path); `detail` supports normalized `crop` [left,top,right,bottom]. Glass is a stylized Fresnel-like surface, not transmission. Avoid chromatic effects on UI and subtitles. Grain and bloom should stay subtle. Background/foreground must contrast. User fonts supported via global font path; renderer selects local display/mono alternatives for editorial hierarchy when present. No fonts are bundled.

## Selection
Start from actual speech timing; do not fabricate duration or word alignment. Select 3–7 *different* compositions in a short video, not all eight automatically. For proof, capture actual screenshots with existing UI tools, choose a crop with readable detail and follow with context. Filmstrip is a montage of a single capture and should not imply two product states. For actual states use separate clips, not fake controls. Keep important content away from platform UI. Artifact is optional and must express a meaningful metaphor. Switching between dark, light, full-bleed and sparse layouts is deliberate; never add a style just to use an effect.

Inspect each shot at 10%, 50%, 90% and both sides of each edit. If a headline clips, shorten or reduce text_scale; if image overlaps speech text, choose split/detail or reduce panel_scale. If UI is unreadable, use a smaller crop and hold longer. If material looks cheap, try ceramic or remove the object. Do not turn a failed shot into an effect stack. Use other unified engines for real data, 3D geometry and semantic morphing. Do not mistake these recipes for full artistic automation.

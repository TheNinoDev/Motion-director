# Brand Motion (v13)
CPU Python/Pillow/NumPy/FFmpeg; no GUI. Render using unified engine `brand`, or standalone `python starter/brand_motion/render.py plan.json output.mp4 --font PATH`. Standalone root width,height,fps, shots with frames; `--frame N` outputs one PNG. Paths relative to plan. Five kinds:
- palette: src screenshot, hues array of 2–12 degree shifts, illustrative=true required; optional caption. Color study, not actual product variants.
- collapse: src screenshot and normalized boxes [left,top,right,bottom] mapped to actual UI content. Source disappears under abstract bars; collapse to center caret. Optional caption.
- reset: blinking caret, optional caption, blink_frames default 12. Minimum 2 frames; use to hold meaningful audio beat.
- badges: title, items array of 1–6 short labels; illustrative=true or evidence_source; actual evidence required for real claims. No fabricated awards. Cards stagger into stable cluster.
- endcard: logo path or brand text, optional tagline and url. Use real assets and check typography. In production give at least 1.5s (prefer 2–2.5s for reading).
Common background, foreground, accent colors, frames. Layouts have fixed normalized anchors. All are original generic motion building blocks. Demo timeline in `../unified/demo.json`. Hue changes and skeletons are stylized mock transitions, no DOM or arbitrary shape morph. Endcard uses flat logo, not authentic curved 3D wordmark. Existing type and scene3d tools can add a metallic motif if needed. No TTS or SFX in this engine; locked soundtrack via unified controller.

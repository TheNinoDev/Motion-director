# Ads Wizard v77 — Kill the relabeled-card slideshow

**ACTIVE RULES.** The user's newest 24.0-second test (1080×1920) has smooth movement but keeps almost every beat in the same layout: top-left headline + centered code/card/diagram + dark-blue grid. This is a STORYBOARD failure, not a renderer or easing failure. Read `references/158-v77-current-film-autopsy.md`, `159-v77-visual-direction-veto.md` and `160-v77-proof-and-finish.md` before planning another film. All prior v76 manuals are support, not permission to add redundant effects. The proven v67 renderer and 15-family SFX library remain intact.

## Creative veto before production

Choose an original visual proposition that a viewer could understand **without a title**. Write a short state chain: **recognizable before → decisive action → visible consequence → seed of the next shot**. Different narration lines need not become different isolated slide panels. Text can clarify or heighten an action; it must not be the only action.

Generate three *structurally different* whole-film stagings in working notes: change the actual spatial/causal story, not just palettes. Reject the default `bold headline + centered UI card + subtle zoom + next headline`. The strongest staging should alter subject role, framing, depth, density, visual focus and spatial relationships as the story advances. Recurring elements create continuity only when their meaning or relationship changes. A static branded grid/background and identical title position throughout does **not** equal coherent art direction.

Before the full film, create a short 8–12-second **picture-first animatic** and inspect it with headline/caption layers hidden when the editor permits. If all that remains is a procession of code cards and panels, delete/rebuild the weak sequence, not its easing. This is an intermediate proof, NOT permission to deliver an unsolicited silent final ad. A genuinely typography-led film is still allowed when letters themselves act as the moving visual proposition rather than labels above a static illustration.

## Editing and finishing

Stage every beat as interacting visual consequences: one actor changes, another responds, framing/camera participates, and the departing object either exits or becomes a justified transition. A purposeful hard cut can be excellent; a decorative wipe cannot rescue two unconnected slide designs. Keep UI controls aligned, avoid accidental overlap, plan exit times, and review actual seams. Prefer the existing editor; a reproducible custom scene compositor is allowed when it better realizes a specific visual direction.

Small licensed Solar/Lucide icons can improve buttons/status cards as finishing details; they are not hero assets or mandatory shot subjects. Rounded controls are allowed but never a substitute for motion design. An explicitly user-authorized product logo may appear in an outro. Do not reuse client-site or reference-film pixels without appropriate individual authorization. The Ads Wizard mascot is the skill's own brand icon only.

Use the actual supplied script, music and narration; don't ask again about known files. If an essential voice/music decision is genuinely missing, follow `references/123-input-and-audio-routing-v60.md`. Author SFX with the v67 library on relevant visible contacts/transformations; don't blanket every new word with the same whoosh.

## Real output test

Watch the *entire* rough cut at 1x, with actual audio. Run `python scripts/visual_story_inspection_v77.py FILM.mp4 --out REVIEW`. View both its normal and blurred-title filmstrips. Ask: if the text were unreadable, would anything important still be happening? If the repeated composition is unmistakable, rethink the staging. This script is a **diagnostic** and cannot score quality. Better still, turn off headline layers in the actual editor to render a temporary text-free animatic.

Use existing `scripts/two_frame_finish_v74.py` for every-other-frame final checks and `scene_ownership_audit_v75.py` when planned geometry exists. Actually inspect the output pages; fix the worst structural error in source and rerender the delivered file. Do not claim that technical tests or numerical pixel activity prove a premium film.

Only use real subagents when available; one director controls continuity and final delivery. Package each release in identical ZIP and .skill archives; publish when verified. Do not fake editorial inspection, product claims, licensing or GitHub status.

**FINAL VETO:** If removing headline/caption text turns your video into a sequence of nearly identical centered cards, it is NOT finished—even when all motions are smooth.
